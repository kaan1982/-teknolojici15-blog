செயற்கை நுண்ணறிவு உதவியாளர்கள் எல்லாவற்றையும் சற்று அறிந்தவை, ஆனால் உன் நிறுவனத்தின் அறிக்கை வார்ப்புருவையோ, பிராண்டின் நிறங்களையோ, ஒரு கோப்பு வகையை சரியாகக் கையாளும் நுட்பங்களையோ அறியாது. இதை ஒவ்வோர் உரையாடலிலும் நீளமாக விளக்குவதற்குப் பதில், ஒருமுறை தொகுத்து முகவரிடம் "தேவைப்படும்போது பயன்படுத்து" என்று சொல்ல முடிந்தால்? "skill" (திறன்) சரியாக இந்த எண்ணம்தான்.

## சுருக்கமாக: ஒரு கோப்புறை மற்றும் ஒரு SKILL.md

Anthropic-இன் வரையறையில் Agent Skills என்பவை Claude-இன் திறன்களை விரிவாக்கும் தொகுதிப் பொதிகள். ஒவ்வொரு skill-உம் அறிவுறுத்தல்கள், மெட்டா தரவு, விருப்பத்தின்பேரில் வளங்களை (ஸ்கிரிப்டுகள், வார்ப்புருக்கள்) ஒன்றாக வைத்திருக்கிறது; Claude இவை தொடர்புடையதாக இருக்கும்போது தானாகவே பயன்படுத்துகிறது. Anthropic-இன் பொறியியல் வலைப்பதிவு இதை இன்னும் எளிமையாகச் சொல்கிறது: skill-கள் என்பவை, குறிப்பிட்ட வேலைகளில் இன்னும் சிறப்பாக இருக்க முகவர் தேவைப்படும் நேரத்தில் ஏற்றிக்கொள்ளும் "ஒழுங்குபடுத்தப்பட்ட அறிவுறுத்தல், ஸ்கிரிப்ட், வளக் கோப்புறைகள்".

தொழில்நுட்ப ரீதியாக ஒரு skill என்பது, குறைந்தபட்சம் உள்ளே SKILL.md என்ற கோப்பு உள்ள கோப்புறை. இந்தக் கோப்பின் தொடக்கத்தில் YAML வடிவில் இரண்டு கட்டாயப் புலங்கள் உள்ளன: name (பெயர்), description (விளக்கம்). அதன் கீழே எளிய Markdown-இல் எழுதப்பட்ட அறிவுறுத்தல்கள் இடம்பெறுகின்றன. விரும்பினால் கோப்புறையில் scripts/ (இயக்கக்கூடிய குறியீடு), references/ (கூடுதல் ஆவணங்கள்), assets/ (வார்ப்புரு, படம், தரவு) போன்ற துணைக் கோப்புறைகளைச் சேர்க்கலாம்.

Anthropic இந்தக் கட்டமைப்பை புதிய பணியாளருக்குத் தயாரிக்கப்படும் வேலை அறிமுக வழிகாட்டியுடன் ஒப்பிடுகிறது. வழிகாட்டியை மேசையில் வைக்கிறாய்; பணியாளர் தேவைப்படும்போது திறந்து பார்க்கிறார்.

## ரகசியம்: எல்லாம் ஒரே நேரத்தில் ஏற்றப்படுவதில்லை

Skill-களை சாதாரண நீண்ட prompt-இலிருந்து வேறுபடுத்துவது "படிப்படியான ஏற்றுதல்" (progressive disclosure) எனப்படும் வடிவமைப்பு. Claude ஆவணங்களின்படி உள்ளடக்கம் மூன்று அடுக்குகளில் ஏற்றப்படுகிறது:

| அடுக்கு | எப்போது ஏற்றப்படுகிறது? |
|---|---|
| 1. மெட்டா தரவு (பெயர் + விளக்கம்) | எப்போதும், தொடக்கத்தில் (ஒரு skill-க்கு சுமார் 100 டோக்கன்) |
| 2. SKILL.md உடல் | Skill தூண்டப்படும்போது (5,000 டோக்கனுக்குள் பரிந்துரைக்கப்படுகிறது) |
| 3. கூடுதல் கோப்புகள், ஸ்கிரிப்டுகள் | தேவைப்படும்போது மட்டும்; ஸ்கிரிப்டுகளின் வெளியீடு மட்டுமே சூழலுக்குள் வரும் |

இதனால் முகவரில் பல பத்து skill-களை ஏற்றலாம், ஆனால் அவை அனைத்தும் சூழல் சாளரத்தை நிரப்புவதில்லை. தூண்டப்படும் வரை ஒவ்வொரு skill-இலிருந்தும் பெயரும் விளக்கமும் மட்டுமே "மேசையில்" இருக்கும். ஆவணத்தில் உள்ள எடுத்துக்காட்டில் PDF skill, படிவம் நிரப்பும் அறிவுறுத்தல்களை தனி forms.md கோப்பில் வைத்திருக்கிறது; Claude இந்தக் கோப்பை உண்மையிலேயே படிவம் நிரப்பும்போது மட்டுமே படிக்கிறது.

> **உனக்குத் தெரியுமா?** Anthropic, Agent Skills-ஐ 16 அக்டோபர் 2025 அன்று அறிவித்து, 18 டிசம்பர் 2025 அன்று வடிவத்தை agentskills.io முகவரியில் திறந்த தரநிலையாக வெளியிட்டது. அதனால் அக்டோபர் 2026 நிலவரப்படி அதே SKILL.md அமைப்பை GitHub Copilot, OpenAI Codex போன்ற பிற கருவிகளின் ஆவணங்களிலும் காணலாம். Copilot-இன் ஆவணங்கள் skill-களைச் சரிபார்க்க நேரடியாக agentskills.io விவரக்குறிப்புக்கு வழிகாட்டுகின்றன.

## Prompt, MCP, செருகுநிரல்: என்ன வேறுபாடு?

இந்தக் கருத்துகள் அடிக்கடி குழப்பப்படுகின்றன, ஏனெனில் எல்லாம் "முகவரை மேம்படுத்துவது" பற்றியவை. Claude உதவி மையத்தின் வேறுபாட்டை இப்படிச் சுருக்கலாம்:

- **Prompt அல்லது தனிப்பயன் அறிவுறுத்தல்கள்:** ஒவ்வோர் உரையாடலிலும் அல்லது எல்லா உரையாடல்களிலும் பொருந்தும் பொது வழிகாட்டுதல்கள். Skill-ஓ பணிக்கே உரியது, தொடர்புடையதாக இருக்கும்போது மட்டுமே செயல்படுகிறது.
- **திட்டங்கள் (Projects):** ஒரு திட்டத்தில் உள்ள உரையாடல்களில் எப்போதும் ஏற்றப்பட்டிருக்கும் நிலையான பின்னணித் தகவல். Skill-ஓ தேவைப்படும்போது திறக்கும் ஒரு நடைமுறை.
- **MCP (Model Context Protocol) இணைப்பிகள்:** Claude-ஐ வெளிச் சேவைகளுடனும் தரவு மூலங்களுடனும் இணைக்கின்றன. அதாவது "அணுகலை" வழங்குகின்றன. Skill-ஓ அந்த அணுகலை எப்படிப் பயன்படுத்துவது என்று சொல்லும் "முறை அறிவு". இரண்டும் அடிக்கடி சேர்ந்து பயன்படுத்தப்படுவதாக உதவி மையம் கூறுகிறது.
- **செருகுநிரல்கள் (plugin):** Claude Code மற்றும் Cowork பக்கத்தில் செருகுநிரல், பல பகுதிகளை (skill-கள், இணைப்பிகள், கட்டளைகள், துணை முகவர்கள்) ஒன்றாக விநியோகிப்பதற்கான பொதி. OpenAI-இன் ஆவணங்களும் இதே போன்ற வேறுபாட்டைச் செய்கின்றன: skill எழுதும் வடிவம், செருகுநிரல் விநியோக வடிவம்.

சுருக்கமாக, MCP முகவருக்குக் கை கொடுக்கிறது, skill அந்தக் கைக்குத் திறமை கற்பிக்கிறது, செருகுநிரல் இவற்றை ஒரு பெட்டியில் ஒப்படைக்கிறது.

## எங்கே இயங்குகிறது?

அக்டோபர் 2026 நிலவரப்படி Claude ஆவணங்களின்படி skill-கள் Claude செயலிகளில் (claude.ai), Claude Code-இல், குறியீடு இயக்கும் கருவியுடன் Claude API-இல் பயன்படுத்தப்படலாம். Skill-கள் Free, Pro, Max, Team, Enterprise திட்டங்களில் வழங்கப்படுகின்றன என்றும், குறியீடு இயக்கும் வசதி இயக்கத்தில் இருக்க வேண்டும் என்றும் உதவி மையம் குறிப்பிடுகிறது.

ஒரு முக்கிய விவரம்: தனிப்பயன் skill-கள் மேற்பரப்புகளுக்கிடையே ஒத்திசைக்கப்படுவதில்லை. claude.ai-இல் நீ பதிவேற்றிய skill உன் கணக்குக்கு மட்டுமே உரியது. API-இல் பதிவேற்றப்பட்ட skill பணியிடம் முழுவதுடனும் பகிரப்படுகிறது. Claude Code-இல் தனிப்பட்ட (~/.claude/skills/) அல்லது திட்டக் கோப்புறையில் (.claude/skills/) வைக்கப்படுகிறது.

பாதுகாப்புப் பரிமாணமும் உண்டு. Skill-கள் குறியீட்டை இயக்க முடிவதால், ஆவணங்கள் அவற்றை "மென்பொருள் நிறுவுவது போல" கையாளவும், நம்பகமான மூலங்களிலிருந்து மட்டுமே பயன்படுத்தவும் பரிந்துரைக்கின்றன. இதைத் தொடரின் கடைசிக் கட்டுரையில் தனியாகப் பார்க்கிறோம்.

இந்தப் பகுதியின் அடுத்த கட்டுரைகளில் உன் சொந்த skill-ஐப் படிப்படியாக எழுதுவதையும், உண்மையிலேயே இருக்கும், பயனுள்ள skill-களை வகைவகையாகவும் ஆராய்வோம்.

நீ ஒவ்வொரு நாளும் செயற்கை நுண்ணறிவிடம் மீண்டும் மீண்டும் விளக்கும், "இதை ஒருமுறை கற்பித்துவிட்டால் நன்றாக இருக்குமே" என்று நினைக்கும் வேலை எது?
