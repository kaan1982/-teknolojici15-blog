Жасанды интеллектке «маған есеп дайында» деу оңай. Қиыны: есептің шынымен ашылатын, пішімі бұзылмайтын, формулалары жұмыс істейтін Word не Excel файлы болып келуі. Skill-дердің бірінші және бәлкім ең көп қолданылатын санаты дәл осы: кеңсе құжаттары. Бұл жазбада тек бар екенін растаған skill-дерді қарастырамыз.

## Төрт негізгі тірек: docx, xlsx, pptx, pdf

Claude құжаттарына сәйкес Anthropic дайын ұсынатын (pre-built) төрт құжат skill-і бар. Олар Claude-тың файл жасау мүмкіндігінің сахна артында жұмыс істейді, ал Anthropic бастапқы кодтарын anthropics/skills GitHub репозиторийінде жариялайды.

| Skill | Не істейді? (ресми сипаттамалардан) |
|---|---|
| docx | Word құжаттарын жасайды, оқиды, өңдейді. Пішімдеу, үлгілерді қоса |
| xlsx | Электрондық кестені ашады, өңдейді, формула мен график қосады, шашыраңқы деректі тазалайды |
| pptx | Презентация жасайды, слайдты өңдейді, .pptx мазмұнын оқып талдайды |
| pdf | Мәтін мен кестені шығарады, PDF біріктіреді, бөледі, форма толтырады, су белгісін қосады |

Репозиторийдегі сипаттамалар біршама «қайсар» жазылған. Мысалы, pptx skill-інің сипаттамасы .pptx файлы кіріс немесе шығыс ретінде «қандай да бір түрде» жұмысқа қатысса, қолдануды айтады. Бұл алдыңғы жазбада айтқан «сипаттама іске қосады» ережесінің ресми мысалы.

## Қайда пайдалана аласың?

2026 жылғы қазан жағдайында Claude құжаттарына сәйкес бұл төрт skill claude.ai-да құжат жасағанда өздігінен іске қосылады және Claude API-да да дайын skill ретінде шақырыла алады. Ал Claude Code-та дайын құжат skill-дері кірістірілген келмейді. Бірақ anthropics/skills репозиторийін Claude Code үшін плагин нарығы ретінде қосуға және document-skills пакетін орнатуға болады. Репозиторийдегі нұсқауға сәйкес алдымен /plugin marketplace add anthropics/skills пәрменімен нарық қосылып, сосын document-skills@anthropic-agent-skills орнатылады.

Лицензия жағынан бір айырмашылық бар. Репозиторийдегі көптеген skill Apache 2.0 лицензиялы ашық бастапқы код. Ал төрт құжат skill-і «ашық бастапқы код емес, бастапқы коды қолжетімді» (source-available) ретінде бөлісілген. Яғни кодты қарап үйрене аласың, бірақ өз өніміңде еркін қайта таратпас бұрын лицензия файлын оқуың керек.

> **Білесің бе?** pdf skill-і кезең-кезеңімен жүктеудің оқулықтағы мысалы. Anthropic-тің инженерлік жазбасына сәйкес форма толтыру нұсқаулары негізгі SKILL.md-ден шығарылып, бөлек forms.md файлына көшірілді. Claude бұл файлды тек шынымен форма толтырғанда оқиды. Репозиторийде pdf қалтасының ішінде бүгін forms.md да, reference.md те және scripts қалтасы да тұр.

## Құжаттың жанындағы көмекшілер

Құжат жасау тек файл пішімімен бітпейді. anthropics/skills репозиторийінде мазмұн жағына назар аударатын басқа ресми мысалдар да бар:

- **doc-coauthoring:** Техникалық ерекшелік, ұсыныс, шешім құжаты сияқты құрылымды мәтіндерді бірге жазу үшін қадамдық жұмыс барысын ұсынады. Контекстті беру, қайталанатын түзету және тексеру кезеңдерінен өткізеді.
- **internal-comms:** Жағдай есебі, басшылық жаңартуы, компания ақпараттық бюллетені, жиі қойылатын сұрақтар сияқты ішкі байланыс мәтіндерін компания қалайтын пішімдерде жазуға көмектесетін ресурстарды жинайды. Қалтада үлгі мәтіндер де бар.
- **brand-guidelines:** Anthropic-тің ресми бренд түстері мен типографиясын шығысқа қолданады. Басты құндылығы: өз брендің үшін ұқсасын қалай құруға болатынын көрсетуінде.
- **theme-factory:** Слайдқа, құжатқа, есепке не HTML бетіне қолдануға болатын 10 дайын түс және қаріп тақырыбын қамтиды, қаласаң бірден жаңа тема да жасайды.

Анықтама орталығы сондай-ақ Notion, Figma және Atlassian сияқты серіктестердің өз MCP коннекторларымен бірге жұмыс істейтіндей дайындаған skill-дерін де атайды. Олар құжаттар жасалатын құралдармен (мыс. Notion беттері) жұмыс істегенде пайдалы.

## Нақты өмірде қалай қолданылады?

Ең тиімді пайдалану: дайын құжат skill-дерін өз шағын skill-іңмен біріктіру. Мысалы, xlsx skill-і Excel-ді қалай дұрыс жасау керектігін біледі, бірақ сенің компанияңның айлық сату кестесінде қандай бағандар болуы керектігін білмейді. Соны түсіндіретін қысқа skill жазсаң, екі skill бірге жұмыс істеп, пішімі де дұрыс, сенің стандартыңа да сай файл шығарады.

Ұмытпауың керек екі ескертпе бар. Біріншісі, anthropics/skills репозиторийі бұл skill-дердің «көрсету және оқыту мақсатында» екенін және Claude-тың өз мінез-құлқы мұндағы қолданбалардан өзгеше болуы мүмкін екенін ашық жазады. Екіншісі, құжат skill-дері код орындау ортасын қажет етеді. Анықтама орталығына сәйкес skill-дердің жұмыс істеуі үшін код орындау мүмкіндігі қосулы болуы керек.

Келесі жазбада экран жағына көшеміз: дизайн, фронтенд және веб шығыстарын жасайтын skill-дер.

Сен ең көп қай құжат түрін дайындағанда уақыт жоғалтасың: кестені ме, презентацияны ма, есепті ме?
