Бағдарлама жазатын адам үшін skill-дер екі жағынан қызық. Біріншіден, өз skill-деріңді жылдамырақ және өлшенетін түрде жазуға көмектесетін «өндіруші» skill-дер бар. Екіншіден, агентке инженерлік тәртіпті (тест, жоспар, қателерді түзету) беретін пакеттер бар. Бұл жазбада екеуін де тек бар екенін растаған мысалдармен қарастырамыз.

## skill-creator: skill жазатын skill

Anthropic-тің ресми anthropics/skills репозиторийіндегі skill-creator жаңа skill жасау, бар skill-дерді өңдеп жақсарту және олардың өнімділігін өлшеу үшін жасалған. Сипаттамасына сәйкес бағалауды (eval) іске қосу, нәтижелерді дисперсиялық талдаумен салыстыру және skill сипаттамасын жақсырақ іске қосылатындай оңтайландыру жұмыстарын да атқарады.

Жұмыс барысы өте адамдық сипатталған: не қалайтыныңды шеш, жоба жаз, бірнеше сынақ хабарламасын дайында, skill-і бар Claude-ты осы хабарламалармен іске қос, нәтижелерді бірге бағала, қайта жаз, қайтала. Қалтада бағалауды іске қосатын, салыстыру есебін шығаратын және сипаттаманы жақсартатын бөлек скрипттер, сондай-ақ нәтижелерді көзбен қарау үшін «eval-viewer» бар.

agentskills.io-ның сипаттаманы оңтайландыру нұсқаулығы да осы skill-ді мысал етеді. Нұсқаулыққа сәйкес skill-creator бұл циклді басынан аяғына дейін автоматтандырады: сынақ жиынын бөледі, іске қосылу қатынасын параллель өлшейді, Claude-пен сипаттама жақсартуларын ұсынады және тірі HTML есебін шығарады.

> **Білесің бе?** agentskills.io ұсынатын іске қосылу тестінде шамамен 20 үлгі хабарлама қолданылады және әрқайсысы 3 рет іске қосылады. Яғни бір сипаттаманы сынау 60 іске қосу деген сөз. Шектен тыс бейімделуді (overfitting) болдырмау үшін хабарламалардың шамамен 60 пайызы жақсарту үшін, 40 пайызы тек тексеру үшін бөлінеді. Нұсқаулық көп жағдайда бес айналым жеткілікті екенін айтады.

## mcp-builder және claude-api: интеграция құратындарға

- **mcp-builder (ресми):** Үлкен тіл модельдерінің сыртқы қызметтермен жақсы жобаланған құралдар арқылы сөйлесуін қамтамасыз ететін MCP серверлерін әзірлеуге арналған нұсқаулық. Python (FastMCP) немесе Node/TypeScript (MCP SDK) арқылы жұмыс істейді. Skill процесті төрт кезеңге бөледі: зерттеу және жоспарлау, іске асыру, қарап шығу және тест, бағалау жасау. Қалтада тілге қарай анықтамалық құжаттар мен бағалау скрипттері бар.
- **claude-api (ресми):** Claude API және Anthropic SDK-ларына арналған анықтамалық skill. Модель идентификаторлары, параметрлер, ағын (streaming), құралды қолдану, кэштеу сияқты тақырыптарды қамтиды және көптеген бағдарламалау тілдеріне бөлек қалталарды қамтиды. Claude құжаттарына сәйкес бұл ашық бастапқы кодты skill Claude Code-пен бірге келеді.
- **webapp-testing (ресми):** Жергілікті веб-қолданбаларды Playwright-пен тестілеуге арналған құрал жинағы. Фронтенд әзірлеушілеріне арналған, дизайн жазбасында да айтқан практикалық көмекші.

## Қауымдастықтан: Superpowers арқылы инженерлік тәртіп

Ресми репозиторийден тыс әзірлеушілер арасында ең көп айтылатын пакеттердің бірі Джесси Винсенттің MIT лицензиялы obra/superpowers репозиторийі. Ол өзін кодтау агенттері үшін «толық бағдарламалық жасақтама әзірлеу әдістемесі» деп сипаттайды. 2026 жылғы қазан жағдайында репозиторийде мына skill-дер бар (таңдама):

| Skill | Қашан іске қосылады? |
|---|---|
| brainstorming | Жаңа мүмкіндікті не шығармашылық жұмысты бастамас бұрын |
| writing-plans | Көп қадамды жұмыс үшін кодқа тиіспей тұрып жоспар жазғанда |
| test-driven-development | Іске асыру кезінде: алдымен сәтсіз тест, сосын ең аз код |
| systematic-debugging | Қатеге не сәтсіз тестке тап болғанда, түзетуді ұсынбас бұрын |
| verification-before-completion | «Бітті» демес бұрын тексеру пәрмендерін іске қосу үшін |

Репозиторий README-і Claude Code-пен қатар Codex, Cursor, Gemini CLI және GitHub Copilot CLI сияқты көптеген агенттерге орнату нұсқауын береді және Claude Code жағында Anthropic-тің ресми плагин нарығында орналасқанын айтады. Бұл Agent Skills-тің ашық стандарт болуының практикалық салдары: бір skill әртүрлі құралдарда жұмыс істей алады.

## Басқа платформаларда да сол идея

OpenAI-дың ChatGPT және Codex құжаттары да skill-дерді «ашық agent skills стандартына» негізделген деп сипаттайды. 2026 жылғы қазан жағдайында құжаттарда екі кірістірілген көмекші ерекшеленеді: сипаттаған жұмыстан skill жасайтын skill-creator (Codex-те $skill-creator арқылы шақырылады) және openai/skills репозиторийінен не басқа репозиторийлерден дайын skill орнататын skill-installer. Codex жергілікті skill-дерді жоба және пайдаланушы деңгейінде .agents/skills қалталарынан оқиды.

Әзірлеуші үшін ең құнды әдет мынау болуы мүмкін: қайталайтын әр ұзақ түсіндірмені, код тексеру тізімін не орналастыру қадамдарын skill-ге айналдырып, жобаның репозиторийіне қою. Claude Code-та .claude/skills қалтасына қойылған skill-дер репозиториймен бірге командаға да барады. Бірақ орнататын әр қауымдастық skill-інің скрипттерін оқуды ұмытпа, өйткені бұл skill-дер компьютеріңде сенің өкілеттіктеріңмен код орындай алады.

Сенің әзірлеу процесіңде қай қадам «skill болса ғой» деуге мәжбүр етеді: тест пе, код тексеру ме, орналастыру ма?
