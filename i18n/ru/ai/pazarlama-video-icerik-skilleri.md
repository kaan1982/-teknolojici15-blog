За этим блогом тоже каждый день создаются короткие видео, обложки и тексты. Поэтому эта категория для нас немного личная: skills для маркетинга, контента и видео. Это и область, где community skills множатся быстрее всего. Мы перечислили только те примеры, репозитории которых открыли и содержимое проверили. Все числа по состоянию на конец октября 2026 года.

## marketingskills: маркетинговая библиотека из 52 skills

Репозиторий coreyhaines31/marketingskills Кори Хейнса, человека за агентством оптимизации конверсии Conversion Factory, с лицензией MIT, одна из самых полных community-коллекций в этой области. Согласно README, он подготовлен для технических маркетологов и основателей и сосредоточен на таких задачах, как оптимизация конверсии, копирайтинг, SEO, аналитика и growth engineering. Заявлено, что он работает с Claude Code, OpenAI Codex, Cursor и другими агентами, поддерживающими стандарт Agent Skills.

В папке skills репозитория 52 skills. Несколько примеров:

- **copywriting:** чтобы писать или улучшать тексты любых маркетинговых страниц, таких как главная страница, посадочная страница, страница с ценами.
- **seo-audit:** чтобы проверять и диагностировать проблемы SEO на сайте.
- **ai-seo:** чтобы оптимизировать контент для ИИ-поисковиков, то есть для того, чтобы большие языковые модели ссылались на него как на источник в своих ответах.
- **emails и cold-email:** для email-цепочек, автоматических потоков и B2B холодных email-кампаний.
- **social:** чтобы создавать и планировать контент для LinkedIn, X, Instagram, TikTok и Facebook.

Для установки README рекомендует команду npx skills add coreyhaines31/marketingskills. Можно выбрать и отдельные skills.

## Маркетинговый плагин Anthropic

Репозиторий Anthropic anthropics/knowledge-work-plugins собирает плагины, подготовленные по профессиональным группам. Они сделаны для Claude Cowork и совместимы с Claude Code. Каждый плагин упаковывает вместе skills, коннекторы, слэш-команды и субагентов для этой работы.

Внутри плагина marketing такие skills: brand-review (проверяет черновик на соответствие голосу бренда и стилевому руководству и предлагает правки «до/после»), campaign-plan (составляет сводку кампании с целью, аудиторией, сообщением, стратегией каналов и контент-календарём), content-creation, draft-content, email-sequence, competitive-brief, performance-report и seo-audit. README перечисляет, что этот плагин может подключаться к таким инструментам, как Slack, Canva, Figma, HubSpot и Ahrefs. То есть здесь skill даёт «метод», а коннектор «доступ».

> **Знал ли ты?** Видео теперь можно создавать не только перетаскиванием на таймлайне, но и кодом, и именно здесь в дело вступают skills. Команда Remotion публикует собственный официальный набор skills для своего видеофреймворка на основе React. HeyGen же предлагает HyperFrames, основанный на идее «пиши HTML, рендери видео», вместе со skills для агентов.

## Для видео: Remotion и HyperFrames

| Пакет | Источник | Что предлагает |
|---|---|---|
| remotion-dev/skills | Команда Remotion (официальный) | 12 skills: создание видео, правила анимации, субтитры, рендер, предпросмотр |
| heygen-com/hyperframes | HeyGen (Apache 2.0) | Skills и готовые блоки для фреймворка, превращающего HTML в видео |

**Remotion:** согласно README, Remotion ведёт список Agent Skills, описывающих лучшие практики работы в проектах Remotion. В наборе есть такие skills, как remotion-create, создающий новое видео, remotion-markup с знаниями об анимации и вёрстке, remotion-captions для расшифровки субтитров и их анимации, remotion-render для экспорта и remotion-best-practices, направляющий ко всем. Установка делается через npx skills add remotion-dev/skills.

**HyperFrames:** репозиторий HeyGen представляет себя как «пиши HTML, рендери видео, сделано для агентов». Согласно README, основной набор состоит из skills hyperframes (создание и редактирование видео), hyperframes-cli (каркас проекта, предпросмотр, рендер), hyperframes-registry (около 450 готовых блоков переходов, заголовков, субтитров и графики) и media-use (медиаработы: музыка, звуковые эффекты, изображения, озвучка). Всего опубликовано 7 skills.

Любопытная деталь: в описании видео-skill из репозитория Кори Хейнса названия вроде Remotion, HyperFrames и HeyGen тоже перечислены как слова-триггеры. То есть маркетинговый skill написан так, чтобы работать как мост к видео-skills.

## На что смотреть при выборе?

Большинство skills в этой области созданы сообществом или компаниями и обновляются очень быстро. Перед установкой пакета полезно задать три вопроса: чей это репозиторий, активно ли он обновляется? Есть ли в SKILL.md инструкции, обращающиеся к внешним адресам или запрашивающие учётные данные? Можешь ли ты выбрать и установить только те несколько skills, что тебе действительно нужны? Большинство инструментов установки позволяют выбрать один skill вместо «установить всё», и это уменьшает и контекст, и риск.

Что в создании контента больше всего ворует у тебя время: писать тексты, готовить визуал или монтировать видео?
