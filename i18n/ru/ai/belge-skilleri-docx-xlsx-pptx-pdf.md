Сказать ИИ «подготовь мне отчёт» легко. Трудно добиться, чтобы отчёт пришёл как файл Word или Excel, который действительно открывается, не ломает форматирование и в котором работают формулы. Первая и, пожалуй, самая используемая категория skills именно об этом: офисные документы. В этой статье мы рассматриваем только те skills, существование которых подтвердили.

## Четыре краеугольных камня: docx, xlsx, pptx, pdf

Согласно документации Claude, у Anthropic есть четыре готовых (pre-built) skills для документов. Они работают за кулисами функции создания файлов в Claude, а Anthropic публикует их исходный код в репозитории GitHub anthropics/skills.

| Skill | Что делает? (по официальным описаниям) |
|---|---|
| docx | Создаёт, читает, редактирует документы Word. Включая форматирование и шаблоны |
| xlsx | Открывает и редактирует электронные таблицы, добавляет формулы и диаграммы, очищает разрозненные данные |
| pptx | Создаёт презентации, редактирует слайды, читает и разбирает содержимое .pptx |
| pdf | Извлекает текст и таблицы, объединяет и разделяет PDF, заполняет формы, добавляет водяные знаки |

Описания в репозитории написаны довольно «настойчиво». Например, описание skill pptx говорит применять его, если файл .pptx «каким-либо образом» участвует как вход или выход. Это официальный пример правила «описание запускает», о котором мы говорили в предыдущей статье.

## Где можно использовать?

По состоянию на октябрь 2026 года, согласно документации Claude, эти четыре skills сами работают в claude.ai при создании документов, а в Claude API их можно вызывать как готовые skills. В Claude Code готовые skills для документов встроенными не поставляются. Но репозиторий anthropics/skills можно добавить в Claude Code как маркетплейс плагинов и установить пакет document-skills. По инструкции в репозитории сначала командой /plugin marketplace add anthropics/skills добавляют маркетплейс, затем устанавливают document-skills@anthropic-agent-skills.

В отношении лицензий есть различие. Многие skills в репозитории с открытым исходным кодом по лицензии Apache 2.0. Однако четыре skills для документов опубликованы как «не open source, а с доступным исходным кодом» (source-available). То есть код можно изучать и учиться на нём, но перед свободным распространением в своём продукте нужно прочесть файл лицензии.

> **Знал ли ты?** Skill pdf это учебниковый пример поэтапной загрузки. Согласно инженерной статье Anthropic, инструкции по заполнению форм вынесли из основного SKILL.md в отдельный файл forms.md. Claude читает этот файл, только когда действительно заполняет форму. В репозитории в папке pdf сегодня лежат и forms.md, и reference.md, и папка scripts.

## Помощники рядом с документом

Создание документов не заканчивается форматом файла. В репозитории anthropics/skills есть и другие официальные примеры, сосредоточенные на содержании:

- **doc-coauthoring:** предлагает пошаговый процесс совместного написания структурированных текстов, таких как техническое задание, предложение, документ с решением. Проводит через этапы передачи контекста, итеративной доработки и проверки.
- **internal-comms:** собирает ресурсы, помогающие писать тексты внутренних коммуникаций, такие как отчёт о статусе, обновление для руководства, корпоративный бюллетень, FAQ, в форматах, предпочитаемых компанией. В папке есть и примеры текстов.
- **brand-guidelines:** применяет к результату официальные фирменные цвета и типографику Anthropic. Главная ценность в том, что показывает, как создать аналог для своего бренда.
- **theme-factory:** содержит 10 готовых цветовых и шрифтовых тем, применимых к слайду, документу, отчёту или HTML-странице, и при желании сразу создаёт новую тему.

Справочный центр также упоминает skills, которые партнёры, такие как Notion, Figma и Atlassian, подготовили для работы вместе с собственными коннекторами MCP. Они пригодятся при работе с инструментами, в которых создаются документы (например, страницы Notion).

## Как использовать в реальной жизни?

Самое продуктивное применение: объединять готовые skills для документов с собственным небольшим skill. Например, skill xlsx знает, как правильно создавать Excel, но не знает, какие столбцы должны быть в ежемесячной таблице продаж твоей компании. Если написать короткий skill, который это описывает, два skill вместе создадут файл и с правильным форматом, и соответствующий твоему стандарту.

Нужно помнить две вещи. Первая: репозиторий anthropics/skills прямо пишет, что эти skills «для демонстрации и обучения» и что поведение самого Claude может отличаться от реализаций здесь. Вторая: skills для документов требуют среды выполнения кода. По данным Справочного центра, для работы skills должна быть включена функция выполнения кода.
