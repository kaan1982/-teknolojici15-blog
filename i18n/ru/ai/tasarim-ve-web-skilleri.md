Если ты просил ИИ сделать веб-страницу, то, вероятно, замечал: результат работает, но откуда-то кажется знакомым. Те же фиолетовые градиенты, тот же центрированный заголовок, та же раскладка карточек. Большая часть skills для дизайна как раз борется с этой проблемой: заставить модель принимать осознанное дизайнерское решение, а не «значение по умолчанию».

Для каждого skill в этой статье мы указали источник. Официальный репозиторий Anthropic anthropics/skills, а репозитории сообщества или компаний отмечены отдельно.

## frontend-design: уйти от значений по умолчанию

Описание skill frontend-design из официального репозитория чёткое: руководство по «осознанному, отличительному визуальному дизайну» при создании нового интерфейса или переработке существующего. Он помогает с выбором эстетического направления, типографики и решений, которые «не читаются как шаблон».

Тело skill ставит модель в роль арт-директора дизайн-студии и начинает работу, предполагая, что клиент уже отверг клишированные предложения. Это тоже пример хорошей техники написания skill: вместо накопления знаний дать модели чёткую точку зрения.

## Веб-результаты: web-artifacts-builder и webapp-testing

- **web-artifacts-builder (официальный):** набор инструментов для создания в claude.ai сложных HTML-результатов из нескольких компонентов, с управлением состоянием или маршрутизацией, на современных фронтенд-технологиях вроде React, Tailwind CSS и shadcn/ui. В его описании сказано и то, что его не следует использовать для простых однофайловых HTML-задач. В папке есть скрипты, инициализирующие проект и упаковывающие его в один файл.
- **webapp-testing (официальный):** набор инструментов для тестирования локальных веб-приложений с помощью Playwright. Служит для проверки фронтенд-функций, отладки ошибок интерфейса, снятия скриншотов и чтения журналов браузера. Ответ на вопрос «а оно правда работает?» после того, как дизайн сделан.

> **Знал ли ты?** Skill theme-factory из официального репозитория поставляется с 10 готовыми темами, применимыми к любому результату, от слайда до HTML-страницы. Даже названия файлов тем в папке вдохновляют: «arctic-frost», «midnight-galaxy», «golden-hour», «tech-innovation» и другие. При желании skill может сразу создать и новую тему.

## Визуальное искусство: canvas-design, algorithmic-art, slack-gif-creator

В репозитории Anthropic есть ещё три skills, представляющих «творческую» сторону:

- **canvas-design:** для создания плакатов, произведений искусства или статичных дизайнов в виде .png и .pdf использует подход «философии дизайна». В папке более 80 файлов шрифтов. В его описании прямо поставлено условие не копировать работы существующих художников.
- **algorithmic-art:** создаёт генеративное искусство с помощью p5.js, с зависимой от начального значения случайностью (seeded randomness) и интерактивными параметрами. Разработан для таких запросов, как поля потоков и системы частиц.
- **slack-gif-creator:** предлагает ограничения, инструменты проверки и идеи анимации для создания анимированных GIF, оптимизированных для Slack. Для запросов вида «сделай мне Slack-GIF, где X делает Y».

## От сообщества: skills Vercel для интерфейса и React

Одним из самых известных пакетов, ориентированных на дизайн, помимо официального репозитория, является репозиторий Vercel vercel-labs/agent-skills. По состоянию на октябрь 2026 года в нём есть следующее:

| Skill | Что делает? |
|---|---|
| web-design-guidelines | Проверяет код интерфейса по более чем 100 правилам, охватывающим доступность, производительность и пользовательский опыт |
| vercel-react-best-practices | Правила производительности React и Next.js от инженеров Vercel (более 40 в 8 категориях) |
| vercel-composition-patterns | Масштабируемые паттерны композиции компонентов React |
| vercel-react-view-transitions | Плавные анимации переходов с помощью View Transition API в React |
| vercel-react-native-skills | Правила производительности и архитектуры для React Native и Expo |

Эти skills не привязаны к одному инструменту. Репозиторий Vercel рекомендует установку командой npx skills add vercel-labs/agent-skills, и skills можно использовать в разных агентах, поддерживающих стандарт Agent Skills.

## Что и когда использовать?

Практическая последовательность может быть такой: определи дизайнерское направление с frontend-design, зафиксируй цвет и шрифт с theme-factory или своим брендовым skill, создай результат с web-artifacts-builder, затем проверь его через web-design-guidelines и опробуй в браузере через webapp-testing. У каждого своя специализация, и благодаря поэтапной загрузке держать все установленными одновременно не раздувает контекст.

Предупреждение: некоторые из этих skills (например, web-artifacts-builder) выполняют скрипты. Документация Claude советует относиться к skills как к установке программ и устанавливать только из источников, которым ты доверяешь. Хорошая привычка заглядывать в SKILL.md и скрипты каждого пакета не из официального репозитория перед установкой.
