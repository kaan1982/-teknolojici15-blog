AI 어시스턴트는 모든 것을 조금씩 알지만, 우리 회사의 보고서 양식이나 브랜드 색상, 특정 파일 형식을 제대로 다루는 요령은 모릅니다. 대화마다 이걸 길게 설명하는 대신 한 번 포장해 두고 에이전트에게 "필요할 때 써"라고 할 수 있다면 어떨까요? "스킬"(skill, 능력)이 바로 그 아이디어입니다.

## 간단히 말해: 폴더 하나와 SKILL.md 하나

Anthropic의 정의에 따르면 Agent Skills는 Claude의 능력을 확장하는 모듈형 패키지입니다. 각 스킬은 지침, 메타데이터, 선택적 리소스(스크립트, 템플릿)를 함께 담고 있으며, Claude는 관련이 있을 때 이를 스스로 사용합니다. Anthropic의 엔지니어링 블로그는 더 간단히 말합니다. 스킬은 에이전트가 특정 작업을 더 잘하려고 필요할 때 불러오는 "정리된 지침, 스크립트, 리소스의 폴더"입니다.

기술적으로 스킬은 최소한 SKILL.md라는 파일이 들어 있는 폴더입니다. 이 파일 맨 앞에는 YAML 형식의 필수 필드 두 개가 있습니다. name(이름)과 description(설명)입니다. 그 아래에는 평범한 Markdown으로 쓴 지침이 있습니다. 원하면 폴더에 scripts/(실행 가능한 코드), references/(추가 문서), assets/(템플릿, 이미지, 데이터) 같은 하위 폴더를 더할 수 있습니다.

Anthropic은 이 구조를 새 직원을 위한 온보딩 가이드에 비유합니다. 가이드를 책상에 두면 직원은 필요할 때 펼쳐 봅니다.

## 비밀: 모든 것이 한꺼번에 로딩되지 않는다

스킬을 평범한 긴 프롬프트와 구별하는 것은 "단계적 로딩"(progressive disclosure)이라는 설계입니다. Claude 문서에 따르면 콘텐츠는 세 단계로 로딩됩니다.

| 단계 | 언제 로딩될까? |
|---|---|
| 1. 메타데이터 (이름 + 설명) | 항상, 시작할 때 (스킬당 약 100토큰) |
| 2. SKILL.md 본문 | 스킬이 작동할 때 (5,000토큰 이하 권장) |
| 3. 추가 파일과 스크립트 | 필요할 때만. 스크립트는 출력만 컨텍스트에 들어감 |

덕분에 에이전트에 수십 개의 스킬을 설치해도 컨텍스트 윈도우가 가득 차지 않습니다. 작동하기 전까지는 각 스킬의 이름과 설명만 "책상 위"에 놓여 있습니다. 문서의 예시에서 PDF 스킬은 양식 채우기 지침을 별도의 forms.md 파일에 두고, Claude는 실제로 양식을 채울 때만 이 파일을 읽습니다.

> **알고 있었나요?** Anthropic은 2025년 10월 16일에 Agent Skills를 발표했고, 2025년 12월 18일에 이 형식을 agentskills.io에서 공개 표준으로 내놓았습니다. 그래서 2026년 10월 기준 같은 SKILL.md 구조를 GitHub Copilot과 OpenAI Codex 같은 다른 도구의 문서에서도 볼 수 있습니다. Copilot 문서는 스킬을 확인하려면 agentskills.io 명세를 직접 참고하라고 안내합니다.

## 프롬프트, MCP, 플러그인: 뭐가 다를까?

이 개념들은 자주 헷갈립니다. 모두 "에이전트를 더 낫게 만든다"와 관련 있기 때문입니다. Claude 고객센터의 구분은 이렇게 요약할 수 있습니다.

- **프롬프트 또는 사용자 지정 지침:** 모든 대화 또는 한 대화에서 적용되는 일반적인 방향 제시. 스킬은 작업에 특화되어 있고 관련이 있을 때만 작동합니다.
- **프로젝트:** 프로젝트 안의 대화에서 항상 로딩되어 있는 고정 배경 지식. 스킬은 필요할 때 펼치는 절차입니다.
- **MCP(Model Context Protocol) 커넥터:** Claude를 외부 서비스와 데이터 소스에 연결합니다. 즉 "접근"을 제공합니다. 스킬은 그 접근을 어떻게 쓸지 알려 주는 "방법 지식"입니다. 고객센터는 둘이 자주 함께 쓰인다고 말합니다.
- **플러그인:** Claude Code와 Cowork에서 플러그인은 여러 조각(스킬, 커넥터, 명령, 하위 에이전트)을 함께 배포하는 패키지입니다. OpenAI 문서도 비슷하게 구분합니다. 스킬은 작성 형식이고 플러그인은 배포 형태입니다.

한마디로 MCP는 에이전트에게 손을 주고, 스킬은 그 손에 기술을 가르치며, 플러그인은 이것들을 한 상자에 담아 전달합니다.

## 어디서 작동할까?

2026년 10월 기준 Claude 문서에 따르면 스킬은 Claude 앱(claude.ai), Claude Code, 그리고 코드 실행 도구와 함께 Claude API에서 사용할 수 있습니다. 고객센터는 스킬이 Free, Pro, Max, Team, Enterprise 요금제에서 제공되며 코드 실행 기능이 켜져 있어야 한다고 밝힙니다.

중요한 세부 사항이 있습니다. 사용자 지정 스킬은 환경 간에 동기화되지 않습니다. claude.ai에 올린 스킬은 내 계정에서만 쓸 수 있습니다. API에 올린 스킬은 워크스페이스 전체와 공유됩니다. Claude Code에서는 개인용(~/.claude/skills/) 또는 프로젝트 폴더(.claude/skills/)에 보관합니다.

보안 측면도 있습니다. 스킬은 코드를 실행할 수 있으므로 문서는 "소프트웨어를 설치하듯" 다루고 신뢰할 수 있는 출처의 것만 쓰라고 권합니다. 이 내용은 시리즈의 마지막 글에서 따로 다룹니다.

이 섹션의 다음 글들에서는 나만의 스킬을 단계별로 쓰는 법과, 실제로 존재하고 쓸모 있는 스킬을 범주별로 살펴봅니다.

여러분이 매일 AI에게 반복해서 설명하면서 "이걸 한 번만 가르쳐 놓으면 좋겠다"고 생각하는 일은 무엇인가요?
