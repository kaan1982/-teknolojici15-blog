소프트웨어를 만드는 사람에게 스킬은 두 가지 면에서 흥미롭습니다. 첫째, 나만의 스킬을 더 빠르고 측정 가능하게 쓰도록 돕는 "제작용" 스킬이 있습니다. 둘째, 에이전트에게 엔지니어링 규율(테스트, 계획, 디버깅)을 심어 주는 패키지가 있습니다. 이 글에서는 둘 다, 존재를 확인한 예시만 다룹니다.

## skill-creator: 스킬을 쓰는 스킬

Anthropic의 공식 저장소 anthropics/skills에 있는 skill-creator는 새 스킬을 만들고, 기존 스킬을 고쳐서 개선하고, 성능을 측정하도록 설계되었습니다. 설명에 따르면 평가(eval) 실행, 분산 분석을 이용한 결과 비교, 스킬 설명을 더 잘 작동하도록 최적화하는 일도 맡습니다.

워크플로는 꽤 사람답게 설명되어 있습니다. 원하는 것을 정하고, 초안을 쓰고, 테스트 메시지 몇 개를 준비하고, 스킬을 장착한 Claude를 그 메시지들로 실행하고, 결과를 함께 평가하고, 다시 쓰고, 반복합니다. 폴더에는 평가를 실행하고 비교 보고서를 만들고 설명을 개선하는 별도의 스크립트와, 결과를 시각적으로 살펴보는 "eval-viewer"가 들어 있습니다.

agentskills.io의 설명 최적화 가이드도 이 스킬을 예로 듭니다. 가이드에 따르면 skill-creator는 이 순환을 처음부터 끝까지 자동화합니다. 테스트 세트를 나누고, 트리거 비율을 병렬로 측정하고, Claude와 함께 설명 개선안을 제안하고, 실시간 HTML 보고서를 만듭니다.

> **알고 있었나요?** agentskills.io가 권하는 트리거 테스트에서는 예시 메시지 약 20개를 쓰고 각각을 3번씩 실행합니다. 설명 하나를 시험하는 데 60번 실행이 필요하다는 뜻입니다. 과적합(overfitting)을 막으려고 메시지의 약 60%는 개선용으로, 40%는 검증용으로만 따로 둡니다. 가이드는 대개 다섯 라운드면 충분하다고 말합니다.

## mcp-builder와 claude-api: 통합을 만드는 사람을 위해

- **mcp-builder (공식):** 대규모 언어 모델이 잘 설계된 도구를 통해 외부 서비스와 대화하도록 하는 MCP 서버를 개발하기 위한 가이드입니다. Python(FastMCP) 또는 Node/TypeScript(MCP SDK)로 작동합니다. 스킬은 과정을 네 단계로 나눕니다. 조사와 계획, 구현, 검토와 테스트, 평가 만들기입니다. 폴더에는 언어별 참고 문서와 평가 스크립트가 있습니다.
- **claude-api (공식):** Claude API와 Anthropic SDK를 위한 참고 스킬입니다. 모델 ID, 매개변수, 스트리밍, 도구 사용, 캐싱 같은 주제를 다루며 여러 프로그래밍 언어별 폴더가 있습니다. Claude 문서에 따르면 이 오픈 소스 스킬은 Claude Code와 함께 제공됩니다.
- **webapp-testing (공식):** 로컬 웹 앱을 Playwright로 테스트하기 위한 도구 모음입니다. 프런트엔드 개발자에게는 디자인 글에서도 언급한 실용적인 도우미입니다.

## 커뮤니티에서: Superpowers로 엔지니어링 규율 갖추기

공식 저장소 밖에서 개발자들 사이에 가장 많이 거론되는 패키지 중 하나는 Jesse Vincent의 MIT 라이선스 저장소 obra/superpowers입니다. 스스로를 코딩 에이전트를 위한 "완전한 소프트웨어 개발 방법론"이라고 소개합니다. 2026년 10월 기준 저장소에는 다음 스킬들이 있습니다(발췌).

| 스킬 | 언제 작동할까? |
|---|---|
| brainstorming | 새 기능이나 창작 작업을 시작하기 전 |
| writing-plans | 여러 단계로 된 작업에서 코드에 손대기 전에 계획을 쓸 때 |
| test-driven-development | 구현 중: 먼저 실패하는 테스트, 그다음 최소한의 코드 |
| systematic-debugging | 버그나 실패한 테스트를 만났을 때, 수정안을 내놓기 전 |
| verification-before-completion | "끝났다"고 말하기 전에 검증 명령을 실행하게 할 때 |

저장소 README는 Claude Code 외에도 Codex, Cursor, Gemini CLI, GitHub Copilot CLI 같은 여러 에이전트의 설치 안내를 제공하며, Claude Code 쪽에서는 Anthropic의 공식 플러그인 마켓에 올라 있다고 밝힙니다. Agent Skills가 공개 표준이라는 점의 실용적인 결과입니다. 같은 스킬이 여러 도구에서 작동할 수 있습니다.

## 다른 플랫폼에도 같은 아이디어

OpenAI의 ChatGPT와 Codex 문서도 스킬을 "공개 agent skills 표준"에 기반한 것으로 설명합니다. 2026년 10월 기준 문서에는 두 가지 내장 도우미가 눈에 띕니다. 설명한 작업으로 스킬을 만들어 주는 skill-creator(Codex에서는 $skill-creator로 호출)와, openai/skills 저장소나 다른 저장소에서 기성 스킬을 설치해 주는 skill-installer입니다. Codex는 로컬 스킬을 프로젝트 수준과 사용자 수준의 .agents/skills 폴더에서 읽습니다.

개발자에게 가장 값진 습관은 이것일지 모릅니다. 반복해서 설명하던 긴 내용, 코드 리뷰 체크리스트, 배포 단계를 스킬로 바꿔 프로젝트 저장소에 넣어 두는 것입니다. Claude Code에서는 .claude/skills 폴더에 둔 스킬이 저장소와 함께 팀에도 전달됩니다. 다만 설치하는 커뮤니티 스킬마다 스크립트를 읽는 것을 잊지 마세요. 이런 스킬은 내 컴퓨터에서 내 권한으로 코드를 실행할 수 있기 때문입니다.

여러분의 개발 과정에서 "이게 스킬이면 좋겠다"는 생각이 가장 자주 드는 단계는 무엇인가요? 테스트인가요, 코드 리뷰인가요, 배포인가요?
