At Teknolojici15 we usually look to the past: the first email, the first floppy disk, the first password. In this section we look at history being written today. AI agents no longer just answer questions: they prepare documents, write code, edit video. The new building block that helps them do this better is called a "skill".

A skill is a simple folder containing a SKILL.md file and optional scripts. The agent loads it only when needed. This format, which Anthropic launched in 2025 and published as an open standard, appears as of October 2026 in the documentation of other tools such as GitHub Copilot and OpenAI Codex too.

In this guide we explain what a skill is, how to write your own, the skills that actually exist for documents, design, development and content creation, and what to watch for when installing them. Every article has sources, and we only name skills whose existence we have verified. Since this field changes very fast, don't forget to glance at the date notes.
