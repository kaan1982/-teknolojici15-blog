Οι βοηθοί τεχνητής νοημοσύνης ξέρουν λίγα για όλα, αλλά δεν ξέρουν το πρότυπο αναφοράς της εταιρείας σου, τα χρώματα του brand σου ή τα κόλπα για να χειριστείς σωστά έναν τύπο αρχείου. Κι αν, αντί να τα εξηγείς διεξοδικά σε κάθε συνομιλία, μπορούσες να τα πακετάρεις μία φορά και να πεις στον πράκτορα «χρησιμοποίησέ το όταν χρειαστεί»; Αυτή ακριβώς είναι η ιδέα του «skill» (δεξιότητα).

## Με δυο λόγια: ένας φάκελος και ένα SKILL.md

Σύμφωνα με τον ορισμό της Anthropic, τα Agent Skills είναι αρθρωτά πακέτα που επεκτείνουν τις δυνατότητες του Claude. Κάθε skill κρατά μαζί οδηγίες, μεταδεδομένα και προαιρετικούς πόρους (σενάρια, πρότυπα), και το Claude τα χρησιμοποιεί από μόνο του όταν είναι σχετικά. Το engineering blog της Anthropic το λέει ακόμη πιο απλά: τα skills είναι «οργανωμένοι φάκελοι με οδηγίες, σενάρια και πόρους» που ο πράκτορας φορτώνει όταν τους χρειάζεται για να γίνει καλύτερος σε συγκεκριμένες δουλειές.

Τεχνικά, ένα skill είναι ένας φάκελος που περιέχει τουλάχιστον ένα αρχείο με όνομα SKILL.md. Στην αρχή αυτού του αρχείου υπάρχουν δύο υποχρεωτικά πεδία σε μορφή YAML: name (όνομα) και description (περιγραφή). Από κάτω ακολουθούν οι οδηγίες, γραμμένες σε απλό Markdown. Αν θέλεις, μπορείς να προσθέσεις στον φάκελο υποφακέλους όπως scripts/ (εκτελέσιμος κώδικας), references/ (πρόσθετα έγγραφα) και assets/ (πρότυπα, εικόνες, δεδομένα).

Η Anthropic παρομοιάζει αυτή τη δομή με τον οδηγό ένταξης που ετοιμάζεται για έναν νέο εργαζόμενο. Αφήνεις τον οδηγό στο γραφείο και ο εργαζόμενος τον ανοίγει όταν τον χρειαστεί.

## Το μυστικό: δεν φορτώνονται όλα μονομιάς

Αυτό που ξεχωρίζει τα skills από ένα συνηθισμένο μακροσκελές prompt είναι ο σχεδιασμός που λέγεται «σταδιακή αποκάλυψη» (progressive disclosure). Σύμφωνα με την τεκμηρίωση του Claude, το περιεχόμενο φορτώνεται σε τρία επίπεδα:

| Επίπεδο | Πότε φορτώνεται; |
|---|---|
| 1. Μεταδεδομένα (όνομα + περιγραφή) | Πάντα, κατά την εκκίνηση (περίπου 100 tokens ανά skill) |
| 2. Το σώμα του SKILL.md | Όταν ενεργοποιείται το skill (προτείνεται κάτω από 5.000 tokens) |
| 3. Πρόσθετα αρχεία και σενάρια | Μόνο όταν χρειάζονται, στο πλαίσιο μπαίνει μόνο το αποτέλεσμα των σεναρίων |

Έτσι μπορείς να φορτώσεις δεκάδες skills στον πράκτορα χωρίς να γεμίζουν όλα το παράθυρο συμφραζομένων. Μέχρι να ενεργοποιηθεί, από κάθε skill «βρίσκεται στο τραπέζι» μόνο το όνομα και η περιγραφή. Στο παράδειγμα της τεκμηρίωσης, το skill για PDF κρατά τις οδηγίες συμπλήρωσης φορμών σε ξεχωριστό αρχείο forms.md, και το Claude διαβάζει αυτό το αρχείο μόνο όταν πραγματικά συμπληρώνει φόρμα.

> **Το ήξερες;** Η Anthropic ανακοίνωσε τα Agent Skills στις 16 Οκτωβρίου 2025 και στις 18 Δεκεμβρίου 2025 δημοσίευσε τη μορφή ως ανοιχτό πρότυπο στο agentskills.io. Γι' αυτό, από τον Οκτώβριο του 2026, βλέπεις την ίδια δομή SKILL.md και στην τεκμηρίωση άλλων εργαλείων όπως το GitHub Copilot και το OpenAI Codex. Η τεκμηρίωση του Copilot παραπέμπει απευθείας στην προδιαγραφή του agentskills.io για τον έλεγχο των skills.

## Prompt, MCP, πρόσθετο: ποια η διαφορά;

Αυτές οι έννοιες μπερδεύονται συχνά, γιατί όλες αφορούν το «να γίνει ο πράκτορας καλύτερος». Η διάκριση του Κέντρου Βοήθειας του Claude συνοψίζεται ως εξής:

- **Prompt ή προσαρμοσμένες οδηγίες:** Γενικές κατευθύνσεις που ισχύουν σε κάθε συνομιλία ή σε όλες. Το skill, αντίθετα, είναι ειδικό για μια εργασία και ενεργοποιείται μόνο όταν είναι σχετικό.
- **Έργα (Projects):** Σταθερές πληροφορίες υποβάθρου που είναι πάντα φορτωμένες στις συνομιλίες ενός έργου. Το skill είναι μια διαδικασία που ανοίγει όταν χρειάζεται.
- **Συνδέσεις MCP (Model Context Protocol):** Συνδέουν το Claude με εξωτερικές υπηρεσίες και πηγές δεδομένων, δηλαδή παρέχουν «πρόσβαση». Το skill είναι η «γνώση της μεθόδου» που εξηγεί πώς να χρησιμοποιηθεί αυτή η πρόσβαση. Το κέντρο βοήθειας λέει ότι τα δύο χρησιμοποιούνται συχνά μαζί.
- **Πρόσθετα (plugins):** Στο Claude Code και το Cowork, το πρόσθετο είναι το πακέτο που διανέμει μαζί πολλά κομμάτια (skills, συνδέσεις, εντολές, υποπράκτορες). Η τεκμηρίωση της OpenAI κάνει παρόμοια διάκριση: το skill είναι η μορφή συγγραφής, το πρόσθετο ο τρόπος διανομής.

Με δυο λόγια, το MCP δίνει χέρι στον πράκτορα, το skill διδάσκει σε αυτό το χέρι μια τέχνη και το πρόσθετο τα παραδίδει όλα σε ένα κουτί.

## Πού λειτουργεί;

Από τον Οκτώβριο του 2026, σύμφωνα με την τεκμηρίωση του Claude, τα skills μπορούν να χρησιμοποιηθούν στις εφαρμογές του Claude (claude.ai), στο Claude Code και στο Claude API μαζί με το εργαλείο εκτέλεσης κώδικα. Το κέντρο βοήθειας αναφέρει ότι τα skills προσφέρονται στα πακέτα Free, Pro, Max, Team και Enterprise και ότι απαιτούν να είναι ενεργή η εκτέλεση κώδικα.

Μια σημαντική λεπτομέρεια: τα προσαρμοσμένα skills δεν συγχρονίζονται ανάμεσα στις επιφάνειες. Ένα skill που ανεβάζεις στο claude.ai είναι αποκλειστικά για τον δικό σου λογαριασμό. Ένα skill που ανεβαίνει στο API μοιράζεται με ολόκληρο τον χώρο εργασίας. Στο Claude Code, φυλάσσεται είτε ως προσωπικό (~/.claude/skills/) είτε στον φάκελο του έργου (.claude/skills/).

Υπάρχει και η πλευρά της ασφάλειας. Επειδή τα skills μπορούν να εκτελούν κώδικα, η τεκμηρίωση προτείνει να τα αντιμετωπίζεις «όπως την εγκατάσταση λογισμικού» και να τα χρησιμοποιείς μόνο από αξιόπιστες πηγές. Το εξετάζουμε χωριστά στο τελευταίο άρθρο της σειράς.

Στα επόμενα άρθρα αυτής της ενότητας θα γράψουμε βήμα προς βήμα το δικό σου skill και θα εξετάσουμε, κατηγορία προς κατηγορία, skills που υπάρχουν πραγματικά και είναι χρήσιμα.

Ποια δουλειά εξηγείς ξανά και ξανά στην τεχνητή νοημοσύνη κάθε μέρα και λες «μακάρι να μπορούσα να της το μάθω μία φορά»;
