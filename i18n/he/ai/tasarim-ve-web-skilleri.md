אם נתתם לבינה מלאכותית לבנות דף אינטרנט, כנראה שמתם לב לכך: התוצאה עובדת אבל משהו בה מוכר. אותם מעברי צבע סגולים, אותה כותרת ממורכזת, אותו סידור כרטיסים. רוב ה-skills לעיצוב מתעסקים בדיוק בבעיה הזו: לגרום למודל לקבל החלטת עיצוב מודעת, ולא לבחור את "ברירת המחדל".

בכל skill בכתבה הזו ציינו את המקור. המאגר הרשמי של Anthropic הוא anthropics/skills, ומאגרי הקהילה או החברות מסומנים בנפרד.

## frontend-design: לברוח מברירת המחדל

התיאור של ה-skill frontend-design במאגר הרשמי ברור: הדרכה ל"עיצוב חזותי מודע ומובחן" בעת בניית ממשק חדש או עיצוב מחדש של קיים. הוא עוזר בבחירת כיוון אסתטי, טיפוגרפיה ובחירות ש"לא נקראות כמו תבנית".

גוף ה-skill מכניס את המודל לתפקיד ראש עיצוב בסטודיו לעיצוב ומתחיל מההנחה שהלקוח כבר דחה את ההצעות הקלישאתיות. זו גם דוגמה לטכניקה טובה בכתיבת skills: במקום לצבור ידע, לתת למודל נקודת מבט ברורה.

## תוצרי אינטרנט: web-artifacts-builder ו-webapp-testing

- **web-artifacts-builder (רשמי):** ערכת כלים ב-claude.ai להפקת תוצרי HTML מורכבים ורב-רכיביים שדורשים ניהול מצב או ניתוב, בטכנולוגיות ממשק קדמי מודרניות כמו React, Tailwind CSS ו-shadcn/ui. התיאור שלו אומר גם שאין להשתמש בו לעבודות HTML פשוטות בקובץ אחד. בתיקייה יש סקריפטים שמאתחלים את הפרויקט ואורזים אותו לקובץ אחד.
- **webapp-testing (רשמי):** ערכת כלים לבדיקת אפליקציות אינטרנט מקומיות עם Playwright. משמשת לאימות פונקציות של הממשק הקדמי, לדיבוג שגיאות ממשק, לצילום מסך ולקריאת יומני הדפדפן. התשובה לשאלה "האם זה באמת עובד?" אחרי שסיימתם לעצב.

> **הידעת?** ה-skill theme-factory במאגר הרשמי מגיע עם 10 ערכות נושא מוכנות שאפשר להחיל על כל תוצר, משקופית ועד דף נחיתה ב-HTML. גם שמות קובצי הערכות בתיקייה מעוררי השראה: "arctic-frost", "midnight-galaxy", "golden-hour", "tech-innovation" ועוד. אם רוצים, ה-skill יכול להפיק ערכת נושא חדשה במקום.

## אמנות חזותית: canvas-design, algorithmic-art, slack-gif-creator

במאגר של Anthropic יש עוד שלושה skills שמייצגים את הצד ה"יצירתי":

- **canvas-design:** משתמש בגישה של "פילוסופיית עיצוב" כדי להפיק פוסטרים, יצירות אמנות או עיצובים סטטיים בקובצי .png ו-.pdf. בתיקייה יש יותר מ-80 קובצי גופנים. התיאור שלו מתנה במפורש שלא להעתיק עבודות של אמנים קיימים.
- **algorithmic-art:** יוצר אמנות גנרטיבית עם p5.js, באמצעות אקראיות עם זרע (seeded randomness) ופרמטרים אינטראקטיביים. מתוכנן לבקשות כמו שדות זרימה ומערכות חלקיקים.
- **slack-gif-creator:** מציע אילוצים, כלי אימות ורעיונות אנימציה להפקת GIF מונפשים שעברו אופטימיזציה ל-Slack. לבקשות בסגנון "עשה לי GIF לסלאק שבו X עושה Y".

## מהקהילה: ה-skills של Vercel לממשק ול-React

מחוץ למאגר הרשמי, אחת החבילות המוכרות ביותר שממוקדות בעיצוב היא המאגר vercel-labs/agent-skills של Vercel. נכון לאוקטובר 2026, במאגר יש:

| Skill | מה הוא עושה? |
|---|---|
| web-design-guidelines | בודק קוד ממשק מול יותר מ-100 כללים שמכסים נגישות, ביצועים וחוויית משתמש |
| vercel-react-best-practices | כללי ביצועים של הנדסת Vercel ל-React ול-Next.js (יותר מ-40 ב-8 קטגוריות) |
| vercel-composition-patterns | תבניות להרכבת רכיבי React שניתנות להרחבה |
| vercel-react-view-transitions | אנימציות מעבר זורמות עם View Transition API של React |
| vercel-react-native-skills | כללי ביצועים וארכיטקטורה ל-React Native ול-Expo |

ה-skills האלה אינם קשורים לכלי אחד. המאגר של Vercel ממליץ להתקין בפקודה npx skills add vercel-labs/agent-skills, וה-skills אפשר להשתמש בהם בסוכנים שונים שתומכים בתקן Agent Skills.

## במה להשתמש ומתי?

סדר מעשי יכול להיות כזה: קבעו את כיוון העיצוב עם frontend-design, קבעו צבע וגופן עם theme-factory או עם skill מותג משלכם, הפיקו את התוצר עם web-artifacts-builder, אחר כך בדקו אותו עם web-design-guidelines ונסו בדפדפן עם webapp-testing. כל אחד הוא התמחות נפרדת, ובזכות הטעינה ההדרגתית החזקת כולם מותקנים במקביל לא מנפחת את ההקשר.

אזהרה: חלק מה-skills האלה (למשל web-artifacts-builder) מריצים סקריפטים. תיעוד Claude ממליץ להתייחס ל-skills כמו להתקנת תוכנה ולהתקין אותם רק ממקורות שאתם סומכים עליהם. מומלץ להציץ ב-SKILL.md ובסקריפטים של כל חבילה שמחוץ למאגר הרשמי לפני שמתקינים אותה.

לדעתכם, האם עיצובים שנעשים בבינה מלאכותית יהפכו עם הזמן למגוונים יותר, או שככל שכולם ישתמשו באותם skills ייוולד "אחידות" חדשה?
