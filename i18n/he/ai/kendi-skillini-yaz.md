כדי לכתוב skill לא צריך להיות מתכנתים. בצורתו הפשוטה ביותר מספיקים תיקייה וקובץ טקסט אחד בתוכה. אבל ההבדל בין skill שעובד היטב לבין skill שלא מופעל בכלל מסתתר לרוב במשפט אחד: התיאור. בכתבה הזו אנחנו כותבים מאפס skill קטן אבל אמיתי.

## שלב 1: צרו את התיקייה ואת SKILL.md

לפי מפרט Agent Skills, skill הוא תיקייה שמכילה לפחות קובץ SKILL.md אחד. בראש הקובץ יש מידע מקדים ב-YAML (frontmatter) ושני שדות חובה:

- **name:** עד 64 תווים. אותיות קטנות, ספרות ומקף בלבד. אסור שיתחיל או יסתיים במקף, אסור שיכיל שני מקפים רצופים, והוא חייב להיות זהה לשם התיקייה. תיעוד Claude מציין גם שאסור להשתמש במילים "anthropic" ו-"claude" בשם.
- **description:** אסור שיהיה ריק, עד 1,024 תווים. עליו להסביר מה ה-skill עושה ומתי להשתמש בו.

יש גם שדות אופציונליים (license, compatibility, metadata ו-allowed-tools הניסיוני), אבל ברוב ה-skills אין בהם צורך.

## שלב 2: כתבו את התיאור בקפידה

למה התיאור כל כך חשוב? כי בהפעלה הסוכן קורא מכל skill רק את השם והתיאור. בניסוח של agentskills.io, "כל נטל" ההפעלה מוטל על התיאור. אם התיאור לא אומר מתי העבודה תועיל, הסוכן לא יושיט יד אל ה-skill הזה.

ההמלצות של המקורות מסוכמות כך:

- כתבו גם **מה הוא עושה** וגם **מתי להשתמש בו**.
- תיעוד Claude ממליץ לכתוב את התיאור ב**גוף שלישי**, כי הוא מוסף להנחיית המערכת ("מעבד קובצי Excel", ולא "אני יכול לעזור לך").
- agentskills.io ממליץ לפרט במפורש גם מצבים שבהם המשתמש לא מזכיר את התחום בשמו.
- שמרו על קיצור: כמה משפטים, לכל היותר פסקה קצרה. Claude Code חותך את התיאור ברשימה ב-1,536 תווים, ולכן מקרה השימוש החשוב ביותר צריך לבוא בהתחלה.

## שלב 3: גוף קצר, סקריפט חכם

כדוגמה נחשוב על skill שמתאים לכלל הכתיבה של הבלוג הזה: שלא יישארו בטקסט מקף ארוך (em dash) ומקף בינוני (en dash). מבנה התיקייה יהיה כזה:

```
tire-denetimi/
├── SKILL.md
└── scripts/
    └── tire_bul.py
```

וקובץ SKILL.md יהיה כזה:

```markdown
---
name: tire-denetimi
description: מוצא שימוש במקף ארוך (U+2014) ובמקף בינוני (U+2013) בכתבות בלוג ומציע תיקון. משמש כשהמשתמש מכין כתבת Markdown לפרסום, כשהוא אומר "בדוק את המקפים" או "האם זה עומד בכללי הכתיבה", או כשהוא מבקש בדיקה אחרונה לפני פרסום גם בלי להזכיר את השם.
---

# בדיקת מקפים

1. הריצו את הפקודה `python scripts/tire_bul.py <dosya.md>`.
2. לכל שורה בפלט הציעו להחליף את המקף בנקודה, בפסיק, בנקודתיים או בסוגריים.
3. אל תשנו את המשמעות. אם אינכם בטוחים לגבי שורה, שאלו את המשתמש.
4. בסוף דווחו במשפט אחד על כמה שורות תוקנו.
```

תיעוד Claude רואה בחלון ההקשר "משאב משותף" וממליץ להוסיף רק מידע שהמודל עדיין לא מכיר. הגוף צריך להישאר מתחת ל-500 שורות. טקסטי עזר ארוכים צריכים לעבור לקבצים נפרדים, ויש לקשר אליהם מ-SKILL.md ברמה אחת בלבד.

גם הכלל לסקריפטים ברור: "פתרו, אל תזרקו את הכדור". כלומר הסקריפט צריך לטפל בעצמו במצבי שגיאה, ולא להיכתב בהיגיון של "שייפול, Claude כבר ימצא דרך". כשהסקריפט רץ, להקשר נכנס רק הפלט שלו, לא הקוד עצמו. וזה הופך סקריפט לאמין יותר מהוראה בעבודות חוזרות שאינן סובלות טעויות.

> **הידעת?** ב-Claude Code, "פקודות הלוכסן המותאמות" הישנות התמזגו עם skills. הקובץ .claude/commands/deploy.md והקובץ .claude/skills/deploy/SKILL.md יוצרים את אותה פקודה /deploy. אם אינכם רוצים ש-skill יופעל אוטומטית, הוסיפו ל-frontmatter את disable-model-invocation: true וקראו לו ידנית בלבד.

## שלב 4: בדקו, ואז בדקו שוב

מדריך השיטות המומלצות של Claude ממליץ להכין תרחישי הערכה לפני כתיבת מסמך ארוך, וברשימת הבדיקה שלפני הפרסום יש לפחות שלוש הערכות ובדיקה נפרדת במודלים Haiku, Sonnet ו-Opus. ההיגיון פשוט: הוראה שעובדת בצורה מושלמת ב-Opus עשויה לדרוש ב-Haiku יותר פירוט.

לבדיקת ההפעלה ההמלצה של agentskills.io קונקרטית: הכינו כ-20 הודעות משתמש לדוגמה. 8 עד 10 מהן צריכות להפעיל את ה-skill, ו-8 עד 10 לא. הדוגמאות השליליות היקרות ביותר הן אלה ש"כמעט פספסו", כלומר הודעות שחולקות אותן מילים אך מבקשות עבודה אחרת. מכיוון שהתנהגות המודל אינה זהה בכל פעם, מומלץ להריץ כל הודעה כמה פעמים (3 להתחלה) ולבחון את שיעור ההפעלה.

| תיאור גרוע | תיאור טוב |
|---|---|
| "עוזר עם קובצי PDF." | אומר מה הוא עושה ומתי להשתמש בו |
| רק פרטים טכניים | מתאר את הכוונה של המשתמש |
| מכסה הכול | מציין גם מה הוא לא עושה |

גם ההתקנה פשוטה: ב-Claude Code מספיק להניח את התיקייה תחת ~/.claude/skills/ (אישי) או בתיקיית .claude/skills/ של הפרויקט. Claude Code עוקב אחרי התיקיות האלה וקולט שינויים באותו מושב בלי צורך בהפעלה מחדש. ב-claude.ai אפשר להעלות את ה-skill כקובץ zip מההגדרות.

איזו משימה חוזרת שלכם ה-skill הראשון שלכם היה מבצע אוטומטית?
