Si tu tapes aujourd'hui info.cern.ch dans ton navigateur, tu arrives à l'adresse du premier site web du monde. Du texte noir, un fond blanc, des liens bleus soulignés. Ni image ni animation. Mais cette page sobre est le point de départ d'un réseau qui atteint aujourd'hui plus d'un milliard de sites.

Il y a juste une petite note de bas de page : la page que tu vois n'est pas exactement l'original de 1991. Nous y viendrons dans un instant.

## Une proposition au CERN, un ordinateur NeXT

En mars 1989, Tim Berners-Lee a écrit au CERN une proposition de système d'information distribué et, en mai 1990, il en a présenté de nouveau une version un peu révisée. Selon la page Web@30 du CERN, à Noël 1990, il avait défini les concepts de base du web (HTML, HTTP et URL), écrit le premier navigateur/éditeur et le premier logiciel serveur.

Le serveur tournait sur un ordinateur NeXT du CERN et son adresse était info.cern.ch. Le premier site web était hébergé sur cette machine et décrivait le projet World Wide Web lui-même : ce qu'est le web, comment l'utiliser, où se procurer le logiciel.

## 6 août 1991 : le web s'ouvre au monde

Le Centre for Computing History écrit que le premier site web a été publié le 6 août 1991. Ce jour-là, Berners-Lee a annoncé le logiciel WWW dans le groupe de discussion alt.hypertext. Selon le CERN, cette annonce a marqué le moment où l'intérêt pour le web a commencé en dehors de la communauté des physiciens.

La date est donc un peu stratifiée : le site fonctionnait à l'intérieur du CERN fin 1990, puis a été annoncé à l'extérieur en août 1991 et est devenu accessible à tous. Les sources peuvent mettre en avant l'une ou l'autre de ces deux dates pour « le premier site web ».

> **Le savais-tu ?** L'ordinateur NeXT, premier serveur web, portait une étiquette écrite à l'encre rouge : "This machine is a server. DO NOT POWER IT DOWN!!" C'est-à-dire : « Cette machine est un serveur. NE PAS L'ÉTEINDRE !! » Tout le web dépendait alors du fait qu'un seul ordinateur reste allumé.

## Alors, que signifie « toujours en ligne » ?

Voilà la note de bas de page. Les fichiers de 1991 du premier site n'ont pas été conservés tels quels. Pour le 20e anniversaire de l'ouverture du web au public, le 30 avril 2013, le CERN a lancé un projet pour rétablir le premier site à son adresse d'origine. Selon CBC News, la version restaurée est une copie datée de 1992 trouvée dans les archives du CERN. D'après CBC, le projet ne visait pas seulement à rétablir la page, mais aussi à restaurer les noms de machines et les adresses IP d'origine, à recréer l'expérience du premier navigateur en mode texte et à documenter le matériel d'origine. Le webmestre du CERN, Dan Noyes, avait déclaré que c'était peut-être « la plus ancienne copie qu'ils pouvaient trouver » et qu'ils continueraient à chercher des versions plus anciennes.

Ce que tu vois aujourd'hui sur info.cern.ch est donc la plus ancienne version du premier site web dont nous disposons. L'adresse est la même, le contenu est un instantané de 1992. Dire « toujours en ligne » est juste, mais dire « la même page est en ligne depuis 35 ans sans jamais s'interrompre » ne l'est pas tout à fait.

Autre date importante : le 30 avril 1993, le CERN a placé le logiciel World Wide Web dans le domaine public. Ce fut l'une des principales raisons pour lesquelles le web s'est répandu si vite comme norme ouverte.

## D'un site à 1,5 milliard

L'enquête Netcraft sur les serveurs web de juillet 2026 indique avoir reçu des réponses de 1 494 915 628 sites. Ce chiffre est un nombre de « sites », pas de noms de domaine ; l'enquête compte à la même période environ 305 millions de noms de domaine uniques. Une grande partie de ces sites n'est pas active. Netcraft écrit dans la même enquête que Cloudflare, avec 50 838 387 sites actifs, représente 23,46 % des sites actifs ; à partir de là, le nombre de sites actifs est d'environ 217 millions, soit seulement 14,5 % environ du total.

| Hier | Aujourd'hui |
|---|---|
| Fin 1990 : 1 site, 1 serveur | Juillet 2026 : environ 1,49 milliard de sites (Netcraft) |
| Texte noir, lien bleu | Vidéo, applications, IA |
| Une étiquette « NE PAS ÉTEINDRE » sur le serveur | Des centres de données répartis dans le monde |
| 1993 : le logiciel tombe dans le domaine public | Le web fonctionne toujours avec des normes ouvertes |

En pensant à ce tableau, on comprend mieux la valeur du premier site. Il n'y a dedans ni publicité, ni avertissement sur les cookies, ni vidéo, ni fenêtre d'abonnement ; seulement du texte et des liens. Mais l'idée de cliquer sur un lien pour passer à un autre document se trouve toujours à la base de chaque page que tu ouvres aujourd'hui.

Un projet qui avait commencé sur un seul ordinateur est devenu, grâce à la décision du CERN d'ouvrir le logiciel à tous, le gigantesque réseau d'aujourd'hui.

Si tu visitais toi aussi info.cern.ch, qu'est-ce qui te surprendrait le plus sur cette première page ?
