Het Chinese AI-bedrijf DeepSeek heeft op 31 oktober de code van Super-Agent op GitHub gepubliceerd, een experimentele codeeragent die is ontworpen voor softwareteams. Volgens Bloomberg wil het bedrijf met deze agent concurreren met tools als Claude Code van Anthropic.

## Wat doet het?

Super-Agent werkt voor één GitHub-repository. Het luistert mee met gesprekken op GitHub en, als je dat wilt, met groepschats in Feishu, de zakelijke chatapp van ByteDance. Vraagt een bevoegd teamlid om een klus, dan opent de agent in zijn eigen sessie een aparte taak, voert het werk uit en plaatst het resultaat, bijvoorbeeld een pull request, onder het gesprek waar het verzoek vandaan kwam. Werk waarvoor een menselijke beslissing nodig is, komt in een lijst op een webpaneel.

Volgens de handleiding van het project is het doel om werk te leveren en het team daarbij "zo weinig mogelijk aandacht" te vragen. Het filosofiedocument van DeepSeek benadrukt dat de agent alleen in actie komt als hem iets gevraagd wordt of als een regel van het team dat toestaat. Het bedrijf waarschuwt dat een agent die namens het hele team werkt ook de aandacht van dat team kan verspillen.

De code is gepubliceerd onder de MIT-licentie: iedereen mag hem downloaden, aanpassen en commercieel gebruiken. In de twee dagen na publicatie verzamelde de repository meer dan 9.000 sterren.

## Wat zijn de beperkingen?

DeepSeek noemt Super-Agent een "onderzoeksprototype" en schrijft duidelijk dat het geen officieel product is. De opensourceversie is niet dezelfde als de versie die het bedrijf intern gebruikt. Sommige ideeën uit de aankondiging zitten nog niet in de code. Het document erkent ook dat lastige problemen zoals autorisatie, review en vertrouwen niet zijn opgelost; gebruikers wordt gevraagd de code te controleren voordat ze hem uitvoeren.

## Waarom is dit belangrijk?

Codeeragents waren tot nu toe vooral tools die wachten op de opdracht van één ontwikkelaar. Super-Agent probeert het idee van een "teamgenoot" uit die zich in de teamchat nestelt en het werk zelf oppakt, en doet dat openlijk, zodat iedereen het kan bekijken. Slaat het idee aan, dan komt de vraag hoeveel bevoegdheid agents krijgen hoog op de agenda van softwareteams te staan.
