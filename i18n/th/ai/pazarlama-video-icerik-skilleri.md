เบื้องหลังบล็อกนี้ก็ผลิตวิดีโอสั้น ภาพปก และข้อความทุกวันเช่นกัน หมวดนี้จึงค่อนข้างเป็นเรื่องส่วนตัวของเรา: skill ที่ผลิตงานการตลาด คอนเทนต์ และวิดีโอ นี่ยังเป็นพื้นที่ที่ skill จากชุมชนเพิ่มจำนวนเร็วที่สุดด้วย เราจึงลงรายการเฉพาะตัวอย่างที่เปิดที่เก็บและตรวจดูข้างในแล้วเท่านั้น ตัวเลขทั้งหมดเป็นของปลายเดือนตุลาคม 2026

## marketingskills: คลังการตลาด 52 skill

ที่เก็บ coreyhaines31/marketingskills ของ Corey Haines เจ้าของชื่อเบื้องหลังเอเจนซีปรับอัตราคอนเวอร์ชัน Conversion Factory ใช้ใบอนุญาต MIT และเป็นหนึ่งในคอลเลกชันจากชุมชนที่ครอบคลุมที่สุดในด้านนี้ ตาม README จัดทำสำหรับนักการตลาดสายเทคนิคและผู้ก่อตั้ง เน้นงานอย่างการปรับอัตราคอนเวอร์ชัน การเขียนคอปปี้ SEO การวิเคราะห์ และวิศวกรรมการเติบโต ระบุว่าทำงานกับ Claude Code, OpenAI Codex, Cursor และเอเจนต์อื่นที่รองรับมาตรฐาน Agent Skills

ในโฟลเดอร์ skills ของที่เก็บมี 52 skill ตัวอย่างบางส่วน:

- **copywriting:** สำหรับเขียนหรือปรับปรุงข้อความของหน้าการตลาดทุกประเภท เช่น หน้าแรก แลนดิงเพจ และหน้าราคา
- **seo-audit:** สำหรับตรวจสอบและวินิจฉัยปัญหา SEO ของเว็บไซต์
- **ai-seo:** สำหรับปรับคอนเทนต์ให้เหมาะกับเสิร์ชเอนจินแบบ AI คือการถูกอ้างเป็นแหล่งที่มาในคำตอบของโมเดลภาษาขนาดใหญ่
- **emails และ cold-email:** สำหรับซีเควนซ์อีเมล โฟลว์อัตโนมัติ และแคมเปญอีเมลเย็นแบบ B2B
- **social:** สำหรับสร้างและวางแผนคอนเทนต์บน LinkedIn, X, Instagram, TikTok และ Facebook

README แนะนำให้ติดตั้งด้วยคำสั่ง npx skills add coreyhaines31/marketingskills และเลือกติดตั้งทีละ skill ก็ได้

## ปลั๊กอินการตลาดของ Anthropic

ที่เก็บ anthropics/knowledge-work-plugins ของ Anthropic รวบรวมปลั๊กอินที่เตรียมไว้ตามสายอาชีพ สร้างสำหรับ Claude Cowork และเข้ากันได้กับ Claude Code แต่ละปลั๊กอินรวม skill ตัวเชื่อม คำสั่งสแลช และเอเจนต์ย่อยสำหรับงานนั้นไว้ในแพ็กเดียว

skill ในปลั๊กอิน marketing ได้แก่ brand-review (ตรวจร่างตามน้ำเสียงแบรนด์และคู่มือสไตล์ แล้วเสนอการแก้ไขแบบก่อน/หลัง), campaign-plan (ทำบรีฟแคมเปญพร้อมเป้าหมาย กลุ่มเป้าหมาย ข้อความ กลยุทธ์ช่องทาง และปฏิทินคอนเทนต์), content-creation, draft-content, email-sequence, competitive-brief, performance-report และ seo-audit README ระบุว่าปลั๊กอินนี้เชื่อมกับเครื่องมืออย่าง Slack, Canva, Figma, HubSpot และ Ahrefs ได้ นั่นคือที่นี่ skill ให้ "วิธีการ" ส่วนตัวเชื่อมให้ "การเข้าถึง"

> **รู้หรือไม่?** ตอนนี้วิดีโอไม่ได้ทำได้แค่ด้วยการลากวางบนไทม์ไลน์ แต่สร้างด้วยโค้ดได้ด้วย และ skill เข้ามามีบทบาทตรงจุดนี้พอดี ทีม Remotion เผยแพร่ชุด skill ทางการของตัวเองสำหรับเฟรมเวิร์กวิดีโอที่สร้างบน React ส่วน HeyGen นำเสนอ HyperFrames ซึ่งตั้งอยู่บนแนวคิด "เขียน HTML แล้วเรนเดอร์เป็นวิดีโอ" มาพร้อม skill สำหรับเอเจนต์

## สำหรับวิดีโอ: Remotion และ HyperFrames

| แพ็กเกจ | แหล่งที่มา | มีอะไรให้ |
|---|---|---|
| remotion-dev/skills | ทีม Remotion (ทางการ) | 12 skill: การสร้างวิดีโอ กฎการทำแอนิเมชัน คำบรรยาย การเรนเดอร์ การพรีวิว |
| heygen-com/hyperframes | HeyGen (Apache 2.0) | skill และบล็อกสำเร็จรูปสำหรับเฟรมเวิร์กที่แปลง HTML เป็นวิดีโอ |

**Remotion:** ตาม README Remotion มีรายการ Agent Skills ที่กำหนดแนวปฏิบัติที่ดีที่สุดในการทำงานกับโปรเจกต์ Remotion ในชุดมี skill เช่น remotion-create ที่สร้างวิดีโอใหม่ remotion-markup ที่เก็บความรู้ด้านแอนิเมชันและเลย์เอาต์ remotion-captions สำหรับถอดเสียงเป็นข้อความและทำแอนิเมชันคำบรรยาย remotion-render สำหรับส่งออก และ remotion-best-practices ที่นำทางไปยังทั้งหมด ติดตั้งด้วย npx skills add remotion-dev/skills

**HyperFrames:** ที่เก็บของ HeyGen แนะนำตัวเองว่า "เขียน HTML เรนเดอร์วิดีโอ สร้างมาเพื่อเอเจนต์" ตาม README ชุดหลักประกอบด้วย skill hyperframes (สร้างและแก้ไขวิดีโอ), hyperframes-cli (โครงโปรเจกต์ พรีวิว เรนเดอร์), hyperframes-registry (บล็อกทรานซิชัน ชื่อเรื่อง คำบรรยาย และกราฟิกสำเร็จรูปราว 450 ชิ้น) และ media-use (งานสื่อ เช่น เพลง เสียงเอฟเฟกต์ ภาพ และเสียงพากย์) รวมมี skill ที่เผยแพร่แล้ว 7 ตัว

รายละเอียดที่น่าสนใจ: คำอธิบายของ skill วิดีโอในที่เก็บของ Corey Haines ก็ระบุชื่ออย่าง Remotion, HyperFrames และ HeyGen เป็นคำกระตุ้น กล่าวคือ skill การตลาดถูกเขียนให้ทำหน้าที่เป็นสะพานไปยัง skill วิดีโอ

## เลือกอย่างไรดี?

skill ในด้านนี้ส่วนใหญ่มาจากชุมชนหรือบริษัท และอัปเดตเร็วมาก ก่อนติดตั้งแพ็กเกจใด ถามสามข้อนี้จะช่วยให้ง่ายขึ้น: ที่เก็บเป็นของใคร ยังอัปเดตอยู่หรือไม่ ใน SKILL.md มีคำสั่งที่เชื่อมไปยังที่อยู่ภายนอกหรือขอข้อมูลรับรองหรือเปล่า และคุณเลือกติดตั้งเฉพาะไม่กี่ skill ที่ต้องใช้จริงได้หรือไม่ เครื่องมือติดตั้งส่วนใหญ่ยอมให้เลือกทีละ skill แทน "ติดตั้งทั้งหมด" ซึ่งลดทั้งบริบทและความเสี่ยง

ในการผลิตคอนเทนต์ อะไรกินเวลาคุณมากที่สุด: การเขียนข้อความ การเตรียมภาพ หรือการตัดต่อวิดีโอ?
