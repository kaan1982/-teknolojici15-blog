สิ่งที่ทำให้ skill ทรงพลังขนาดนี้ก็คือสิ่งที่ทำให้มันเสี่ยงด้วย: skill ไม่ได้มีแค่ข้อความ แต่พกโค้ดที่รันได้มาด้วย เมื่อเอเจนต์โหลด skill มันจะทำตามคำสั่งในนั้นเหมือนเป็นคำสั่งของตัวเองและรันสคริปต์ของมันได้ ข้อแนะนำจากเอกสารของ Claude จึงสรุปได้ในประโยคเดียว: ปฏิบัติต่อการติดตั้ง skill เหมือนการติดตั้งซอฟต์แวร์

## แหล่งทางการว่าอย่างไร?

ส่วนความปลอดภัยในเอกสารของ Claude ตรงไปตรงมามาก แนะนำให้ใช้ skill จากแหล่งที่เชื่อถือได้เท่านั้น คือที่คุณเขียนเองหรือได้มาจาก Anthropic ถ้าจำเป็นต้องใช้ skill จากแหล่งที่ไม่รู้จัก ขอให้ระมัดระวัง "อย่างยิ่ง" และตรวจสอบให้ทั่วก่อนใช้

บทความวิศวกรรมของ Anthropic ก็เป็นไปในแนวเดียวกัน: สำหรับ skill จากแหล่งที่เชื่อถือน้อยกว่า ให้ตรวจไฟล์ที่ถูกแพ็กมา โดยเฉพาะไลบรารีโค้ดและสคริปต์ และตรวจคำสั่งที่บอกให้เชื่อมต่อกับเครือข่ายภายนอก เอกสารยังเน้นความเสี่ยงข้อหนึ่งเป็นพิเศษ: skill ที่ดึงข้อมูลจากที่อยู่ภายนอกนั้นอันตราย เพราะเนื้อหาที่ดึงมาอาจมีคำสั่งประสงค์ร้าย

## ในโลกจริงเกิดอะไรขึ้น?

คำเตือนเหล่านี้ไม่ใช่แค่ทฤษฎี บริษัทความปลอดภัย Snyk สแกน skill 3,984 ตัวจาก ClawHub และ skills.sh ในงานวิจัย "ToxicSkills" ที่เผยแพร่เมื่อวันที่ 5 กุมภาพันธ์ 2026 ผลลัพธ์:

| สิ่งที่พบ | จำนวน |
|---|---|
| skill ที่สแกน | 3,984 |
| มีปัญหาความปลอดภัยอย่างน้อยหนึ่งข้อ | 1,467 (36.82 เปอร์เซ็นต์) |
| มีปัญหาร้ายแรงอย่างน้อยหนึ่งข้อ | 534 (13.4 เปอร์เซ็นต์) |
| เพย์โหลดประสงค์ร้ายที่ยืนยันแล้ว | 76 |

ตามรายงาน ข้อมูลจาก skills.sh ครอบคลุมเฉพาะ 100 skill แรกที่คัดเลือกของเว็บไซต์นั้น ส่วนตัวเลขตลาดแบบเต็มเป็นของ ClawHub รูปแบบการโจมตีที่พบมีทั้งคำแนะนำการติดตั้งที่พาผู้ใช้ไปดาวน์โหลดและรันซอฟต์แวร์ที่ไม่น่าเชื่อถือ คำสั่งที่ซ่อนไว้ (พรางด้วย Base64 หรือ Unicode) ซึ่งส่งข้อมูลรับรองไปให้ผู้โจมตี รวมถึงความพยายามปิดการตรวจสอบความปลอดภัยและฝังช่องทางลับ ใน skill ประสงค์ร้ายที่ยืนยันแล้ว 91 เปอร์เซ็นต์ใช้การฉีดพรอมต์ (prompt injection)

> **รู้หรือไม่?** ตามศูนย์ช่วยเหลือ Claude องค์กรระดับ Enterprise เปิดใช้การสแกน skill ที่ตรวจ skill และปลั๊กอินที่อัปโหลดว่ามีเนื้อหาประสงค์ร้ายหรือไม่ได้ แต่นั่นเป็นแค่ตาข่ายนิรภัย ไม่อาจแทนการอ่านเองได้ วิธีที่ดีที่สุดที่จะรู้ว่า skill ทำอะไรคือเปิด SKILL.md และสคริปต์ขึ้นมาอ่านเองก่อนติดตั้ง

## รายการตรวจสอบก่อนติดตั้ง

รายการเชิงปฏิบัติที่เราสรุปจากคำแนะนำในเอกสารและสิ่งที่พบในสนามจริง:

1. **ตรวจสอบแหล่งที่มา** ที่เก็บเป็นของใคร เป็นบริษัททางการหรือนักพัฒนาที่รู้จักหรือไม่ หรือเป็นสำเนาที่เลียนชื่อแพ็กเกจที่รู้จัก (typosquatting)
2. **อ่าน SKILL.md ตั้งแต่ต้นจนจบ** ประโยคอย่าง "ดาวน์โหลดสิ่งนี้แล้วรันก่อน" "ปิดการตั้งค่าความปลอดภัย" "ส่งไปยังที่อยู่นี้" คือสัญญาณเตือน
3. **ตรวจโฟลเดอร์ scripts/** ถ้ามีบรรทัดที่อ่านไม่ออก ถูกซ่อน หรือเข้ารหัสด้วย Base64 อย่าติดตั้ง
4. **ตรวจลิงก์ภายนอก** ถ้า skill ดึงคำสั่งหรือข้อมูลจากที่อยู่เว็บ จำไว้ว่าเนื้อหานั้นเปลี่ยนได้ทุกเมื่อ
5. **ติดตั้งเฉพาะที่ต้องใช้** การเลือกทีละ skill แทน "ติดตั้งทั้งหมด" ลดทั้งบริบทและพื้นที่ที่ถูกโจมตีได้

## สิทธิ์ขั้นต่ำและกุญแจลับ

skill ทำงานที่ไหนก็สำคัญ ตามเอกสารของ Claude ในสภาพแวดล้อม Claude API skill ไม่มีการเข้าถึงเครือข่ายและติดตั้งแพ็กเกจระหว่างทำงานไม่ได้ ใน claude.ai การเข้าถึงเครือข่ายอาจเต็มรูปแบบ บางส่วน หรือปิด ขึ้นอยู่กับการตั้งค่าของผู้ใช้และผู้ดูแล ส่วนใน Claude Code skill เข้าถึงเครือข่ายได้เท่ากับโปรแกรมใดก็ตามบนคอมพิวเตอร์ของคุณ นั่นคือ skill ที่คุณติดตั้งบนเอเจนต์ในเครื่องทำงานด้วยสิทธิ์ของคุณ

ด้วยเหตุนี้หลักการสิทธิ์ขั้นต่ำจึงสำคัญยิ่ง ใน Claude Code ช่อง allowed-tools ใน frontmatter ของ skill ทำให้เครื่องมือบางอย่างถูกใช้ได้โดยไม่ต้องขออนุญาตเมื่อ skill นั้นถูกเรียก ตามเอกสาร สิทธิ์นี้จะรีเซ็ตในข้อความถัดไปของคุณ อย่างไรก็ตาม ถ้าเห็นสิทธิ์กว้างใน skill ที่คนอื่นเขียน นิสัยที่ดีคืออย่าติดตั้งจนกว่าจะอนุมัติอย่างตั้งใจ

กฎสำหรับกุญแจลับนั้นง่าย: อย่าเขียนคีย์ API รหัสผ่าน หรือโทเค็นการเข้าถึงลงใน SKILL.md หรือโฟลเดอร์ของ skill เด็ดขาด เมื่อคุณแชร์ skill หรือส่งขึ้นที่เก็บ ทุกอย่างในโฟลเดอร์นั้นก็ไปด้วย เก็บคีย์ไว้ในตัวแปรสภาพแวดล้อมหรือที่เก็บข้อมูลรับรองที่ปลอดภัยของเครื่องมือที่คุณใช้ แล้วบอก skill แค่ว่าจะเข้าถึงมันอย่างไร

ณ เดือนตุลาคม 2026 ระบบนิเวศของ skill โตเร็วมาก และการเติบโตนี้ชวนให้นึกถึงปัญหาความปลอดภัยในช่วงปีแรก ๆ ของแอปสโตร์ ข่าวดีคือ การอ่าน skill ง่ายกว่าการอ่านซอร์สโค้ดของแอปมาก เพราะส่วนใหญ่เป็นข้อความธรรมดา

คุณเปิดอ่านข้างในก่อนติดตั้ง skill หรือเชื่อจากจำนวนดาวและตัวเลขดาวน์โหลด?
