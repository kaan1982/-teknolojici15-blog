ถ้าคุณเคยให้ AI ทำหน้าเว็บ คุณน่าจะสังเกตเห็นว่า ผลลัพธ์ใช้งานได้ แต่ดูคุ้นตาอยู่ที่ไหนสักแห่ง ไล่เฉดสีม่วงแบบเดียวกัน หัวข้อจัดกลางแบบเดียวกัน การจัดวางการ์ดแบบเดียวกัน skill ด้านการออกแบบส่วนใหญ่ก็จัดการกับปัญหานี้นี่เอง: ทำให้โมเดลตัดสินใจเรื่องดีไซน์อย่างมีเจตนา ไม่ใช่ใช้ "ค่าเริ่มต้น"

เราระบุแหล่งที่มาของทุก skill ในบทความนี้ไว้แล้ว ที่เก็บทางการของ Anthropic คือ anthropics/skills ส่วนที่เก็บของชุมชนหรือบริษัทมีเครื่องหมายแยกไว้

## frontend-design: หลีกหนีค่าเริ่มต้น

คำอธิบายของ skill frontend-design ในที่เก็บทางการชัดเจน: เป็นแนวทางสำหรับ "งานออกแบบภาพที่มีเจตนาและโดดเด่น" เมื่อสร้างอินเทอร์เฟซใหม่หรือปรับโฉมอันที่มีอยู่ ช่วยเรื่องทิศทางสุนทรียะ ตัวอักษร และการเลือกที่ "อ่านแล้วไม่เหมือนเทมเพลต"

เนื้อหาของ skill ให้โมเดลสวมบทหัวหน้าทีมดีไซน์ของสตูดิโอออกแบบ และเริ่มงานโดยสมมติว่าลูกค้าปฏิเสธข้อเสนอแบบคลิเชอยู่แล้ว นี่เป็นตัวอย่างของเทคนิคการเขียน skill ที่ดีด้วย: แทนที่จะอัดข้อมูลเข้าไป ให้มุมมองที่ชัดเจนแก่โมเดล

## ผลงานเว็บ: web-artifacts-builder และ webapp-testing

- **web-artifacts-builder (ทางการ):** ชุดเครื่องมือสำหรับสร้างผลลัพธ์ HTML ที่ซับซ้อนและมีหลายคอมโพเนนต์ ซึ่งต้องจัดการสถานะหรือการกำหนดเส้นทาง ใน claude.ai ด้วยเทคโนโลยีหน้าบ้านสมัยใหม่อย่าง React, Tailwind CSS และ shadcn/ui คำอธิบายระบุด้วยว่าไม่ควรใช้กับงาน HTML ไฟล์เดียวแบบง่าย ในโฟลเดอร์มีสคริปต์ที่เริ่มโปรเจกต์และรวมเป็นไฟล์เดียว
- **webapp-testing (ทางการ):** ชุดเครื่องมือสำหรับทดสอบเว็บแอปในเครื่องด้วย Playwright ใช้ตรวจสอบฟังก์ชันหน้าบ้าน ดีบักข้อผิดพลาดของอินเทอร์เฟซ ถ่ายภาพหน้าจอ และอ่านล็อกของเบราว์เซอร์ เป็นคำตอบของคำถาม "ใช้งานได้จริงไหม?" หลังออกแบบเสร็จ

> **รู้หรือไม่?** skill theme-factory ในที่เก็บทางการมาพร้อมธีมสำเร็จรูป 10 แบบ ที่ใช้กับผลงานได้ทุกอย่างตั้งแต่สไลด์ไปจนถึงแลนดิงเพจ HTML แม้แต่ชื่อไฟล์ธีมในโฟลเดอร์ก็สร้างแรงบันดาลใจ เช่น "arctic-frost", "midnight-galaxy", "golden-hour", "tech-innovation" และถ้าต้องการ skill ก็สร้างธีมใหม่ให้ทันทีได้

## ศิลปะภาพ: canvas-design, algorithmic-art, slack-gif-creator

ในที่เก็บของ Anthropic ยังมี skill ฝั่ง "สร้างสรรค์" อีกสามตัว:

- **canvas-design:** ใช้แนวทาง "ปรัชญาการออกแบบ" เพื่อผลิตโปสเตอร์ งานศิลปะ หรือดีไซน์ภาพนิ่งเป็นไฟล์ .png และ .pdf ในโฟลเดอร์มีไฟล์ฟอนต์กว่า 80 ไฟล์ คำอธิบายระบุชัดว่าห้ามลอกเลียนผลงานของศิลปินที่มีอยู่
- **algorithmic-art:** สร้างศิลปะเชิงกำเนิดด้วย p5.js โดยใช้การสุ่มแบบมีเมล็ด (seeded randomness) และพารามิเตอร์แบบโต้ตอบ ออกแบบสำหรับคำขออย่างฟิลด์การไหลและระบบอนุภาค
- **slack-gif-creator:** ให้ข้อจำกัด เครื่องมือตรวจสอบ และไอเดียแอนิเมชันสำหรับสร้าง GIF เคลื่อนไหวที่ปรับให้เหมาะกับ Slack สำหรับคำขอแนว "ทำ GIF Slack ที่ X กำลังทำ Y ให้หน่อย"

## จากชุมชน: skill ด้านอินเทอร์เฟซและ React ของ Vercel

นอกจากที่เก็บทางการ หนึ่งในชุดที่เน้นการออกแบบซึ่งรู้จักกันดีที่สุดคือที่เก็บ vercel-labs/agent-skills ของ Vercel ณ เดือนตุลาคม 2026 ในที่เก็บมี:

| Skill | ทำอะไร |
|---|---|
| web-design-guidelines | ตรวจโค้ดอินเทอร์เฟซตามกฎกว่า 100 ข้อ ครอบคลุมการเข้าถึง ประสิทธิภาพ และประสบการณ์ผู้ใช้ |
| vercel-react-best-practices | กฎประสิทธิภาพ React และ Next.js จากทีมวิศวกรรมของ Vercel (กว่า 40 ข้อใน 8 หมวด) |
| vercel-composition-patterns | รูปแบบการประกอบคอมโพเนนต์ React ที่ขยายตัวได้ |
| vercel-react-view-transitions | แอนิเมชันการเปลี่ยนผ่านลื่นไหลด้วย View Transition API ของ React |
| vercel-react-native-skills | กฎด้านประสิทธิภาพและสถาปัตยกรรมสำหรับ React Native และ Expo |

skill เหล่านี้ไม่ได้ผูกกับเครื่องมือเดียว ที่เก็บของ Vercel แนะนำให้ติดตั้งด้วยคำสั่ง npx skills add vercel-labs/agent-skills และ skill ใช้ได้กับเอเจนต์หลายตัวที่รองรับมาตรฐาน Agent Skills

## ควรใช้ตัวไหนเมื่อไร?

ลำดับเชิงปฏิบัติอาจเป็นดังนี้: กำหนดทิศทางการออกแบบด้วย frontend-design ตรึงสีและฟอนต์ด้วย theme-factory หรือ skill แบรนด์ของคุณเอง สร้างผลงานด้วย web-artifacts-builder จากนั้นตรวจด้วย web-design-guidelines และลองในเบราว์เซอร์ด้วย webapp-testing แต่ละตัวเป็นความเชี่ยวชาญแยกกัน และด้วยการโหลดทีละขั้น การติดตั้งทั้งหมดไว้พร้อมกันก็ไม่ทำให้บริบทบวม

คำเตือนข้อหนึ่ง: skill เหล่านี้บางตัว (เช่น web-artifacts-builder) รันสคริปต์ เอกสารของ Claude แนะนำให้ปฏิบัติต่อ skill เหมือนการติดตั้งซอฟต์แวร์และติดตั้งจากแหล่งที่คุณเชื่อถือเท่านั้น การดู SKILL.md และสคริปต์ของทุกแพ็กเกจนอกที่เก็บทางการก่อนติดตั้งเป็นนิสัยที่ดี

คุณคิดว่างานออกแบบที่ทำด้วย AI จะหลากหลายขึ้นเมื่อเวลาผ่านไป หรือเมื่อทุกคนใช้ skill ชุดเดียวกัน จะเกิด "ความเหมือนกันหมด" แบบใหม่ขึ้นมา?
