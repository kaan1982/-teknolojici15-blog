## marketingskills: 52 skills کی مارکیٹنگ لائبریری

کنورژن آپٹیمائزیشن ایجنسی Conversion Factory کے پیچھے موجود نام Corey Haines کی MIT لائسنس والی coreyhaines31/marketingskills ریپوزٹری اس شعبے میں کمیونٹی کے سب سے جامع مجموعوں میں سے ایک ہے۔ README کے مطابق یہ تکنیکی مارکیٹرز اور بانیوں کے لیے تیار ہوئی ہے؛ کنورژن آپٹیمائزیشن، کاپی رائٹنگ، SEO، تجزیات اور گروتھ انجینئرنگ جیسے کاموں پر مرکوز ہے۔ وہ بتاتی ہے کہ یہ Claude Code، OpenAI Codex، Cursor اور Agent Skills معیار کو سپورٹ کرنے والے دوسرے ایجنٹس کے ساتھ کام کرتی ہے۔

ریپوزٹری کے skills فولڈر میں 52 skills ہیں۔ چند مثالیں:

- **copywriting:** ہوم پیج، لینڈنگ پیج، قیمتوں کے صفحے جیسے ہر طرح کے مارکیٹنگ صفحے کا متن لکھنے یا بہتر کرنے کے لیے۔
- **seo-audit:** کسی سائٹ کے SEO مسائل کا آڈٹ اور تشخیص کرنے کے لیے۔
- **ai-seo:** مواد کو مصنوعی ذہانت کے سرچ انجنوں کے لیے بہتر بنانے کے لیے، یعنی بڑے لسانی ماڈلز کے جوابات میں ماخذ کے طور پر دکھائے جانے کے لیے۔
- **emails اور cold-email:** ای میل سیریز، خودکار فلو اور B2B کولڈ ای میل مہمات کے لیے۔
- **social:** LinkedIn، X، Instagram، TikTok اور Facebook کے لیے مواد بنانے اور منصوبہ بندی کرنے کے لیے۔

انسٹالیشن کے لیے README کمانڈ npx skills add coreyhaines31/marketingskills تجویز کرتا ہے۔ ایک ایک skill بھی چنی جا سکتی ہے۔

## Anthropic کا مارکیٹنگ پلگ ان

Anthropic کی anthropics/knowledge-work-plugins ریپوزٹری پیشہ ورانہ گروہوں کے مطابق تیار پلگ ان جمع کرتی ہے۔ یہ Claude Cowork کے لیے بنے ہیں اور Claude Code کے ساتھ بھی ہم آہنگ ہیں۔ ہر پلگ ان اس کام کے لیے skills، کنیکٹرز، سلیش کمانڈز اور ذیلی ایجنٹس کو ایک ساتھ پیک کرتا ہے۔

marketing پلگ ان کی skills یہ ہیں: brand-review (مسودے کو برانڈ کی آواز اور اسٹائل گائیڈ کے مطابق جانچ کر پہلے/بعد کی درستیاں تجویز کرتی ہے)، campaign-plan (ہدف، سامعین، پیغام، چینل کی حکمتِ عملی اور مواد کے کیلنڈر کے ساتھ مہم کا خلاصہ بناتی ہے)، content-creation، draft-content، email-sequence، competitive-brief، performance-report اور seo-audit۔ README فہرست دیتا ہے کہ یہ پلگ ان Slack، Canva، Figma، HubSpot اور Ahrefs جیسے ٹولز سے جڑ سکتا ہے۔ یعنی یہاں skill "طریقہ" اور کنیکٹر "رسائی" فراہم کرتا ہے۔

> **کیا آپ جانتے ہیں؟** ویڈیوز اب صرف ٹائم لائن میں ڈریگ اینڈ ڈراپ سے نہیں، کوڈ سے بھی بنائی جا سکتی ہیں، اور skills بالکل اسی جگہ کام آتی ہیں۔ Remotion ٹیم React پر مبنی ویڈیو فریم ورک کے لیے اپنا سرکاری skill سیٹ شائع کرتی ہے۔ HeyGen "HTML لکھو، ویڈیو رینڈر کرو" کے خیال پر مبنی HyperFrames کو ایجنٹس کے لیے skills کے ساتھ پیش کرتا ہے۔

## چنتے وقت کن باتوں کا خیال رکھیں؟

اس شعبے کی زیادہ تر skills کمیونٹی یا کمپنیوں کی طرف سے آتی ہیں اور بہت تیزی سے اپ ڈیٹ ہوتی ہیں۔ کوئی پیکیج انسٹال کرنے سے پہلے یہ تین سوال کام آسان کرتے ہیں: ریپوزٹری کس کی ہے اور کیا فعال طور پر اپ ڈیٹ ہو رہی ہے؟ کیا SKILL.md میں بیرونی پتوں سے جڑنے یا شناختی معلومات مانگنے والی کوئی ہدایت ہے؟ کیا آپ واقعی اپنی ضرورت کی چند skills چن کر انسٹال کر سکتے ہیں؟ انسٹالیشن ٹولز میں سے اکثر "سب انسٹال کرو" کے بجائے ایک ایک skill چننے دیتے ہیں اور یہ سیاق اور خطرہ دونوں کو چھوٹا کرتا ہے۔
