مصنوعی ذہانت سے کہنا آسان ہے کہ "مجھے ایک رپورٹ بنا دو"۔ مشکل یہ ہے کہ رپورٹ ایسی Word یا Excel فائل کی شکل میں آئے جو واقعی کھل سکے، جس کی فارمیٹنگ نہ بگڑے اور جس کے فارمولے چلیں۔ Skills کا پہلا اور شاید سب سے زیادہ استعمال ہونے والا زمرہ بالکل یہی ہے: دفتری دستاویزات۔ اس تحریر میں ہم صرف وہی skills لیتے ہیں جن کے وجود کی ہم نے تصدیق کی ہے۔

## چار بنیادی پتھر: docx، xlsx، pptx، pdf

Claude دستاویزات کے مطابق Anthropic کی تیار (pre-built) پیش کردہ چار دستاویز skills ہیں۔ یہ Claude کی فائل بنانے کی صلاحیت کے پس منظر میں چلتی ہیں اور Anthropic ان کا سورس کوڈ anthropics/skills GitHub ریپوزٹری میں شائع کرتا ہے۔

| Skill | کیا کرتی ہے؟ (سرکاری وضاحتوں سے) |
|---|---|
| docx | Word دستاویزات بناتی، پڑھتی، ایڈٹ کرتی ہے۔ فارمیٹنگ اور ٹیمپلیٹس سمیت |
| xlsx | اسپریڈ شیٹ کھولتی اور ایڈٹ کرتی ہے، فارمولے اور چارٹ شامل کرتی ہے، بکھرے ڈیٹا کو صاف کرتی ہے |
| pptx | پریزنٹیشن بناتی ہے، سلائیڈز ایڈٹ کرتی ہے، .pptx کا مواد پڑھ کر الگ کرتی ہے |
| pdf | متن اور جدولیں نکالتی ہے، PDF جوڑتی اور توڑتی ہے، فارم بھرتی ہے، واٹر مارک لگاتی ہے |

ریپوزٹری کی وضاحتیں کافی "اصرار" سے لکھی گئی ہیں۔ مثلاً pptx skill کی وضاحت کہتی ہے کہ اگر کوئی .pptx فائل ان پٹ یا آؤٹ پٹ کے طور پر "کسی بھی طرح" کام میں شامل ہو تو اسے استعمال کیا جائے۔ یہ پچھلی تحریر میں بیان کیے گئے "وضاحت متحرک کرتی ہے" اصول کی سرکاری مثال ہے۔

## کہاں استعمال کر سکتے ہیں؟

اکتوبر 2026 تک Claude دستاویزات کے مطابق یہ چار skills claude.ai میں دستاویز بناتے وقت خود بخود فعال ہوتی ہیں اور Claude API میں بھی تیار skill کے طور پر بلائی جا سکتی ہیں۔ Claude Code میں تیار دستاویز skills بلٹ ان نہیں آتیں۔ لیکن anthropics/skills ریپوزٹری کو Claude Code کے لیے پلگ ان مارکیٹ کے طور پر شامل کیا جا سکتا ہے اور document-skills پیکیج انسٹال ہو سکتا ہے۔ ریپوزٹری کی ہدایت کے مطابق پہلے /plugin marketplace add anthropics/skills کمانڈ سے مارکیٹ شامل کی جاتی ہے، پھر document-skills@anthropic-agent-skills انسٹال ہوتا ہے۔

لائسنس کے بارے میں ایک فرق ہے۔ ریپوزٹری کی بہت سی skills Apache 2.0 لائسنس والی اوپن سورس ہیں۔ لیکن چار دستاویز skills "اوپن سورس نہیں، سورس تک رسائی والی" (source-available) کے طور پر شیئر کی گئی ہیں۔ یعنی آپ کوڈ دیکھ کر سیکھ سکتے ہیں، مگر اپنی مصنوعات میں آزادانہ دوبارہ تقسیم کرنے سے پہلے لائسنس فائل پڑھنا ضروری ہے۔

> **کیا آپ جانتے ہیں؟** pdf skill مرحلہ وار لوڈنگ کی نصابی مثال ہے۔ Anthropic کی انجینئرنگ تحریر کے مطابق فارم بھرنے کی ہدایات مرکزی SKILL.md سے نکال کر الگ forms.md فائل میں منتقل کر دی گئیں۔ Claude اس فائل کو صرف تب پڑھتا ہے جب واقعی فارم بھرنا ہو۔ ریپوزٹری میں pdf فولڈر کے اندر آج forms.md، reference.md اور ایک scripts فولڈر موجود ہیں۔

## دستاویز کے ساتھ معاون

دستاویز سازی صرف فائل فارمیٹ پر ختم نہیں ہوتی۔ anthropics/skills ریپوزٹری میں مواد کے پہلو پر مرکوز دوسری سرکاری مثالیں بھی ہیں:

- **doc-coauthoring:** تکنیکی تفصیلات، تجاویز، فیصلے کی دستاویزات جیسی منظم تحریریں مل کر لکھنے کے لیے قدم بہ قدم ورک فلو دیتی ہے۔ سیاق منتقل کرنے، بار بار درست کرنے اور تصدیق کے مراحل سے گزارتی ہے۔
- **internal-comms:** اسٹیٹس رپورٹ، انتظامیہ کی اپ ڈیٹ، کمپنی نیوز لیٹر، اکثر پوچھے گئے سوالات جیسی اندرونی ابلاغ کی تحریریں کمپنی کے پسندیدہ فارمیٹ میں لکھنے میں مدد کرنے والے وسائل جمع کرتی ہے۔ فولڈر میں نمونہ متن بھی ہیں۔
- **brand-guidelines:** Anthropic کے سرکاری برانڈ رنگ اور ٹائپوگرافی کسی آؤٹ پٹ پر لاگو کرتی ہے۔ اس کی اصل قدر یہ دکھانا ہے کہ آپ اپنے برانڈ کے لیے ایسی ہی چیز کیسے بنا سکتے ہیں۔
- **theme-factory:** سلائیڈ، دستاویز، رپورٹ یا HTML صفحے پر لاگو ہو سکنے والے 10 تیار رنگ اور فونٹ تھیمز رکھتی ہے، اور چاہیں تو فوری نیا تھیم بھی بناتی ہے۔

ہیلپ سینٹر ان skills کا بھی ذکر کرتا ہے جو Notion، Figma اور Atlassian جیسے کاروباری شراکت داروں نے اپنے MCP کنیکٹرز کے ساتھ کام کرنے کے لیے تیار کیں۔ یہ ان ٹولز (مثلاً Notion صفحات) کے ساتھ کام کرتے وقت کارآمد ہیں جن میں دستاویزات بنتی ہیں۔

## عملی زندگی میں کیسے استعمال کریں؟

سب سے مؤثر استعمال تیار دستاویز skills کو اپنی چھوٹی skill کے ساتھ ملانا ہے۔ مثلاً xlsx skill جانتی ہے کہ Excel ٹھیک سے کیسے بنایا جاتا ہے، لیکن یہ نہیں جانتی کہ آپ کی کمپنی کی ماہانہ فروخت کی جدول میں کون سے کالم ہونے چاہئیں۔ یہ بتانے والی چھوٹی skill آپ لکھ دیں تو دونوں skills مل کر کام کرتی ہیں اور درست فارمیٹ والی، آپ کے معیار کے مطابق فائل سامنے آتی ہے۔

دو باتیں یاد رکھنا ضروری ہیں۔ پہلی، anthropics/skills ریپوزٹری صاف لکھتی ہے کہ یہ skills "مظاہرے اور تعلیم کے لیے" ہیں اور Claude کا اپنا رویہ یہاں کی عملی صورتوں سے مختلف ہو سکتا ہے۔ دوسری، دستاویز skills کو کوڈ ایگزیکیوشن ماحول درکار ہے۔ ہیلپ سینٹر کے مطابق skills کے کام کرنے کے لیے کوڈ ایگزیکیوشن فیچر کا کھلا ہونا ضروری ہے۔

اگلی تحریر میں ہم اسکرین کی طرف جاتے ہیں: ڈیزائن، فرنٹ اینڈ اور ویب آؤٹ پٹ بنانے والی skills۔

آپ سب سے زیادہ کون سی دستاویز تیار کرنے میں وقت ضائع کرتے ہیں: جدول، پریزنٹیشن یا رپورٹ؟
