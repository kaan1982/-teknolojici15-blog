مصنوعی ذہانت کے اسسٹنٹ ہر چیز تھوڑی بہت جانتے ہیں، لیکن آپ کی کمپنی کا رپورٹ ٹیمپلیٹ، آپ کے برانڈ کے رنگ یا کسی فائل قسم کو ٹھیک سے سنبھالنے کی ترکیبیں نہیں جانتے۔ اگر آپ یہ ہر گفتگو میں لمبی وضاحت کے بجائے ایک بار پیک کر کے ایجنٹ سے کہہ سکتے کہ "ضرورت پر استعمال کرو"؟ "Skill" (ہنر) بالکل یہی خیال ہے۔

## مختصراً: ایک فولڈر اور ایک SKILL.md

Anthropic کی تعریف کے مطابق Agent Skills ایسے ماڈیولر پیکیج ہیں جو Claude کی صلاحیتیں بڑھاتے ہیں۔ ہر skill ہدایات، میٹا ڈیٹا اور اختیاری وسائل (اسکرپٹس، ٹیمپلیٹس) ایک ساتھ رکھتی ہے اور Claude انہیں متعلقہ ہونے پر خود استعمال کرتا ہے۔ Anthropic کا انجینئرنگ بلاگ اسے اور بھی سادہ الفاظ میں کہتا ہے: skills "منظم ہدایات، اسکرپٹس اور وسائل کے فولڈر" ہیں جنہیں ایجنٹ مخصوص کاموں میں بہتر ہونے کے لیے ضرورت کے لمحے لوڈ کرتا ہے۔

تکنیکی طور پر skill ایک فولڈر ہے جس میں کم از کم SKILL.md نامی فائل ہو۔ اس فائل کے شروع میں YAML فارمیٹ کے دو لازمی فیلڈ ہیں: name (نام) اور description (وضاحت)۔ نیچے سادہ Markdown میں لکھی ہدایات ہوتی ہیں۔ فولڈر میں آپ چاہیں تو scripts/ (قابلِ عمل کوڈ)، references/ (اضافی دستاویزات) اور assets/ (ٹیمپلیٹ، تصویر، ڈیٹا) جیسے ذیلی فولڈر بھی شامل کر سکتے ہیں۔

Anthropic اس ساخت کو نئے ملازم کے لیے تیار کردہ تعارفی گائیڈ سے تشبیہ دیتا ہے۔ گائیڈ میز پر رکھ دیتے ہیں، ملازم ضرورت پڑنے پر کھول کر دیکھ لیتا ہے۔

## راز: سب کچھ ایک ساتھ لوڈ نہیں ہوتا

Skills کو عام لمبے پرامپٹ سے الگ کرنے والی چیز "مرحلہ وار لوڈنگ" (progressive disclosure) نامی ڈیزائن ہے۔ Claude دستاویزات کے مطابق مواد تین تہوں میں لوڈ ہوتا ہے:

| تہہ | کب لوڈ ہوتی ہے؟ |
|---|---|
| 1. میٹا ڈیٹا (نام + وضاحت) | ہمیشہ، آغاز پر (فی skill تقریباً 100 ٹوکن) |
| 2. SKILL.md کا متن | جب skill متحرک ہو (5,000 ٹوکن سے کم کی سفارش) |
| 3. اضافی فائلیں اور اسکرپٹس | صرف ضرورت پر؛ اسکرپٹس کا صرف آؤٹ پٹ سیاق میں آتا ہے |

اس طرح آپ ایجنٹ میں درجنوں skills لوڈ کر سکتے ہیں مگر سب سیاق کی کھڑکی کو نہیں بھرتیں۔ متحرک ہونے تک ہر skill کا صرف نام اور وضاحت "میز پر" رہتی ہے۔ دستاویز کی مثال میں PDF skill فارم بھرنے کی ہدایات الگ forms.md فائل میں رکھتی ہے اور Claude اسے صرف تب پڑھتا ہے جب واقعی فارم بھرنا ہو۔

> **کیا آپ جانتے ہیں؟** Anthropic نے Agent Skills کا اعلان 16 اکتوبر 2025 کو کیا اور 18 دسمبر 2025 کو فارمیٹ کو agentskills.io پر کھلے معیار کے طور پر شائع کیا۔ اسی لیے اکتوبر 2026 تک آپ وہی SKILL.md ساخت GitHub Copilot اور OpenAI Codex جیسے دوسرے ٹولز کی دستاویزات میں بھی دیکھتے ہیں۔ Copilot کی دستاویزات skills جانچنے کے لیے براہِ راست agentskills.io کی تفصیلات کی طرف رہنمائی کرتی ہیں۔

## پرامپٹ، MCP، پلگ ان: فرق کیا ہے؟

یہ تصورات اکثر گڈمڈ ہو جاتے ہیں کیونکہ سب "ایجنٹ کو بہتر بنانے" سے متعلق ہیں۔ Claude ہیلپ سینٹر کی تفریق یوں سمیٹی جا سکتی ہے:

- **پرامپٹ یا حسبِ ضرورت ہدایات:** ہر گفتگو یا تمام گفتگوؤں پر لاگو عمومی رہنمائی۔ Skill کام کے لیے مخصوص ہے اور صرف متعلقہ ہونے پر متحرک ہوتی ہے۔
- **پروجیکٹس:** کسی پروجیکٹ کی گفتگوؤں میں ہمیشہ لوڈ رہنے والی مستقل پس منظر معلومات۔ Skill ضرورت پر کھلنے والا طریقۂ کار ہے۔
- **MCP (Model Context Protocol) کنیکٹرز:** Claude کو بیرونی سروسز اور ڈیٹا ذرائع سے جوڑتے ہیں۔ یعنی "رسائی" دیتے ہیں۔ Skill اس رسائی کو برتنے کا "طریقہ جاننے" کا علم ہے۔ ہیلپ سینٹر کہتا ہے کہ دونوں اکثر ساتھ استعمال ہوتے ہیں۔
- **پلگ ان:** Claude Code اور Cowork میں پلگ ان کئی اجزا (skills، کنیکٹرز، کمانڈز، ذیلی ایجنٹس) کو ساتھ تقسیم کرنے کا پیکیج ہے۔ OpenAI کی دستاویزات بھی ایسا ہی فرق کرتی ہیں: skill تحریر کا فارمیٹ ہے، پلگ ان تقسیم کی شکل۔

مختصراً MCP ایجنٹ کو ہاتھ دیتا ہے، skill اس ہاتھ کو ہنر سکھاتی ہے، اور پلگ ان انہیں ایک ڈبے میں پہنچاتا ہے۔

## کہاں کام کرتی ہے؟

اکتوبر 2026 تک Claude دستاویزات کے مطابق skills Claude ایپس (claude.ai)، Claude Code اور کوڈ ایگزیکیوشن ٹول کے ساتھ Claude API میں استعمال کی جا سکتی ہیں۔ ہیلپ سینٹر بتاتا ہے کہ skills Free، Pro، Max، Team اور Enterprise پلانز میں دستیاب ہیں اور کوڈ ایگزیکیوشن فیچر کا کھلا ہونا ضروری ہے۔

ایک اہم تفصیل: حسبِ ضرورت skills مختلف سطحوں کے درمیان سنک نہیں ہوتیں۔ claude.ai پر اپ لوڈ کی گئی skill صرف آپ کے اکاؤنٹ کے لیے ہے۔ API پر اپ لوڈ کی گئی skill پوری ورک اسپیس کے ساتھ شیئر ہوتی ہے۔ Claude Code میں یہ ذاتی (~/.claude/skills/) یا پروجیکٹ فولڈر (.claude/skills/) میں رکھی جاتی ہے۔

سکیورٹی کا پہلو بھی ہے۔ چونکہ skills کوڈ چلا سکتی ہیں، دستاویزات انہیں "سافٹ ویئر انسٹال کرنے" کی طرح لینے اور صرف قابلِ اعتماد ذرائع سے استعمال کرنے کی سفارش کرتی ہیں۔ اس پر ہم سیریز کی آخری تحریر میں الگ بات کرتے ہیں۔

اس حصے کی اگلی تحریروں میں ہم قدم بہ قدم اپنی skill لکھنا اور واقعی موجود، کارآمد skills کو زمرہ بہ زمرہ دیکھیں گے۔

وہ کون سا کام ہے جو آپ مصنوعی ذہانت کو روز بار بار سمجھاتے ہیں اور سوچتے ہیں "کاش یہ ایک بار سکھا دوں"؟
