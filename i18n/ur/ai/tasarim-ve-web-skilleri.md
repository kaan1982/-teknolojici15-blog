اگر آپ نے مصنوعی ذہانت سے ویب پیج بنوایا ہے تو غالباً یہ محسوس کیا ہو گا: نتیجہ کام کرتا ہے مگر کہیں سے جانا پہچانا لگتا ہے۔ وہی جامنی گریڈینٹ، وہی بیچ میں رکھا عنوان، وہی کارڈز کی ترتیب۔ ڈیزائن skills کا بڑا حصہ بالکل اسی مسئلے سے نمٹتا ہے: ماڈل سے "ڈیفالٹ" نہیں بلکہ سوچا سمجھا ڈیزائن فیصلہ کروانا۔

اس تحریر کی ہر skill کا ماخذ ہم نے بتایا ہے۔ Anthropic کی سرکاری ریپوزٹری anthropics/skills ہے، کمیونٹی یا کمپنیوں کی ریپوزٹریز الگ نشان زد ہیں۔

## frontend-design: ڈیفالٹ سے بچنا

سرکاری ریپوزٹری کی frontend-design skill کی وضاحت صاف ہے: نیا انٹرفیس بناتے ہوئے یا موجودہ کو نئی شکل دیتے ہوئے "سوچے سمجھے، منفرد بصری ڈیزائن" کی رہنمائی۔ یہ جمالیاتی سمت، ٹائپوگرافی اور "ٹیمپلیٹ کی طرح نہ پڑھے جانے والے" انتخاب کرنے میں مدد کرتی ہے۔

Skill کا متن ماڈل کو ڈیزائن اسٹوڈیو کے ڈیزائن لیڈ کے کردار میں رکھتا ہے اور یہ فرض کر کے کام شروع کرواتا ہے کہ کلائنٹ گھسی پٹی تجاویز پہلے ہی رد کر چکا ہے۔ یہ اچھی skill لکھنے کی تکنیک کی بھی مثال ہے: معلومات کا ڈھیر لگانے کے بجائے ماڈل کو واضح نقطۂ نظر دینا۔

## ویب آؤٹ پٹ: web-artifacts-builder اور webapp-testing

- **web-artifacts-builder (سرکاری):** claude.ai میں React، Tailwind CSS اور shadcn/ui جیسی جدید فرنٹ اینڈ ٹیکنالوجیز سے کئی اجزا والے، اسٹیٹ مینجمنٹ یا روٹنگ کے متقاضی پیچیدہ HTML آؤٹ پٹ بنانے کا ٹول سیٹ۔ اس کی وضاحت یہ بھی کہتی ہے کہ سادہ ایک فائل والے HTML کاموں کے لیے استعمال نہ کی جائے۔ فولڈر میں پروجیکٹ شروع کرنے اور اسے ایک فائل میں پیک کرنے والے اسکرپٹس ہیں۔
- **webapp-testing (سرکاری):** مقامی ویب ایپلیکیشنز کو Playwright سے ٹیسٹ کرنے کا ٹول سیٹ۔ فرنٹ اینڈ کے فنکشنز کی تصدیق، انٹرفیس کی خرابیاں ڈھونڈنے، اسکرین شاٹ لینے اور براؤزر لاگز پڑھنے کے کام آتا ہے۔ ڈیزائن مکمل کرنے کے بعد "کیا واقعی کام کرتا ہے؟" کا جواب۔

> **کیا آپ جانتے ہیں؟** سرکاری ریپوزٹری کی theme-factory skill سلائیڈ سے HTML لینڈنگ پیج تک ہر آؤٹ پٹ پر لاگو ہو سکنے والے 10 تیار تھیمز کے ساتھ آتی ہے۔ فولڈر کی تھیم فائلوں کے نام بھی متاثر کن ہیں: "arctic-frost"، "midnight-galaxy"، "golden-hour"، "tech-innovation" جیسے۔ آپ چاہیں تو skill فوری نیا تھیم بھی بنا سکتی ہے۔

## بصری فن: canvas-design، algorithmic-art، slack-gif-creator

Anthropic کی ریپوزٹری میں "تخلیقی" پہلو کی نمائندگی کرنے والی تین اور skills ہیں:

- **canvas-design:** پوسٹر، فن پارے یا ساکن ڈیزائن .png اور .pdf میں بنانے کے لیے "ڈیزائن فلسفے" کا طریقہ استعمال کرتی ہے۔ فولڈر میں 80 سے زیادہ فونٹ فائلیں ہیں۔ اس کی وضاحت موجودہ فنکاروں کے کام کی نقل نہ کرنے کی صراحت سے شرط لگاتی ہے۔
- **algorithmic-art:** p5.js کے ساتھ، بیج والی بے ترتیبی (seeded randomness) اور انٹرایکٹو پیرامیٹرز کے ساتھ تخلیقی فن بناتی ہے۔ فلو فیلڈز، پارٹیکل سسٹمز جیسی فرمائشوں کے لیے ڈیزائن کی گئی ہے۔
- **slack-gif-creator:** Slack کے لیے بہتر بنائی گئی اینیمیٹڈ GIFs بنانے کی پابندیاں، تصدیقی ٹولز اور اینیمیشن کے خیالات پیش کرتی ہے۔ "مجھے X کا Y کرتا ہوا Slack GIF بنا دو" طرز کی فرمائشوں کے لیے۔

## کمیونٹی سے: Vercel کی انٹرفیس اور React skills

سرکاری ریپوزٹری سے باہر ڈیزائن پر مرکوز سب سے معروف پیکیجز میں سے ایک Vercel کی vercel-labs/agent-skills ریپوزٹری ہے۔ اکتوبر 2026 تک ریپوزٹری میں یہ ہیں:

| Skill | کیا کرتی ہے؟ |
|---|---|
| web-design-guidelines | انٹرفیس کوڈ کو رسائی، کارکردگی اور صارف تجربے کا احاطہ کرنے والے 100 سے زیادہ اصولوں پر جانچتی ہے |
| vercel-react-best-practices | Vercel انجینئرنگ کے React اور Next.js کارکردگی کے اصول (8 زمروں میں 40 سے زیادہ) |

| vercel-react-view-transitions | React کی View Transition API سے رواں ٹرانزیشن اینیمیشنز |
| vercel-react-native-skills | React Native اور Expo کے لیے کارکردگی اور ساخت کے اصول |

یہ skills کسی ایک ٹول سے بندھی نہیں۔ Vercel کی ریپوزٹری npx skills add vercel-labs/agent-skills کمانڈ سے انسٹالیشن تجویز کرتی ہے اور skills Agent Skills معیار کو سپورٹ کرنے والے مختلف ایجنٹس میں استعمال ہو سکتی ہیں۔

## کب کون سی استعمال کریں؟

ایک عملی ترتیب یہ ہو سکتی ہے: ڈیزائن کی سمت frontend-design سے طے کریں، رنگ اور فونٹ theme-factory یا اپنی برانڈ skill سے مقرر کریں، آؤٹ پٹ web-artifacts-builder سے بنائیں، پھر web-design-guidelines سے جانچیں اور webapp-testing سے براؤزر میں آزمائیں۔ ہر ایک الگ مہارت ہے، اور مرحلہ وار لوڈنگ کی بدولت سب کو ایک ساتھ انسٹال رکھنا سیاق کو نہیں پھلاتا۔

ایک انتباہ: ان میں سے بعض skills (مثلاً web-artifacts-builder) اسکرپٹس چلاتی ہیں۔ Claude دستاویزات skills کو سافٹ ویئر انسٹال کرنے کی طرح لینے اور صرف بھروسے کے ذرائع سے انسٹال کرنے کی سفارش کرتی ہیں۔ سرکاری ریپوزٹری سے باہر آنے والے ہر پیکیج کو انسٹال کرنے سے پہلے اس کے SKILL.md اور اسکرپٹس پر نظر ڈالنا اچھی عادت ہے۔

آپ کے خیال میں مصنوعی ذہانت سے بنے ڈیزائن وقت کے ساتھ زیادہ متنوع ہوں گے، یا سب کے ایک جیسی skills استعمال کرنے سے ایک نئی "یکسانیت" پیدا ہو گی؟
