## سرکاری ذرائع کیا کہتے ہیں؟

Claude دستاویزات کا سکیورٹی حصہ کافی صاف ہے۔ وہ skills کو صرف قابلِ اعتماد ذرائع سے، یعنی اپنی لکھی ہوئی یا Anthropic سے لی ہوئی، استعمال کرنے کی سفارش کرتا ہے۔ اگر آپ کو نامعلوم ذریعے سے skill استعمال کرنی ہی پڑے تو "انتہائی احتیاط" برتنے اور استعمال سے پہلے اسے شروع سے آخر تک جانچنے کو کہتا ہے۔

Anthropic کی انجینئرنگ تحریر بھی اسی لائن پر ہے: کم قابلِ اعتماد ذرائع سے آنے والی skills میں پیک کی گئی فائلوں، خاص طور پر کوڈ انحصار اور اسکرپٹس کا جائزہ لینے اور بیرونی نیٹ ورکس سے جڑنے کی ہدایات کو جانچنے کی سفارش کرتی ہے۔ دستاویزات ایک خطرے پر خاص زور دیتی ہیں: بیرونی پتوں سے ڈیٹا کھینچنے والی skills خطرناک ہیں، کیونکہ کھینچا گیا مواد بدنیتی پر مبنی ہدایات رکھ سکتا ہے۔

رپورٹ کے مطابق skills.sh کا ڈیٹا صرف اس سائٹ کی منتخب پہلی 100 skills کا احاطہ کرتا ہے، جبکہ مکمل مارکیٹ کے اعداد ClawHub کے ہیں۔ دیکھی گئی حملوں کی اقسام میں صارف کو غیر معتبر سافٹ ویئر ڈاؤن لوڈ کر کے چلانے کی طرف لے جانے والی انسٹالیشن ہدایات، شناختی معلومات حملہ آور کو بھیجنے والی چھپائی گئی (Base64 یا Unicode سے بھیس بدلی ہوئی) کمانڈز، اور سکیورٹی چیک بند کرنے اور بیک ڈور لگانے کی کوششیں شامل ہیں۔ تصدیق شدہ بدنیتی والی skills کے 91 فیصد میں پرامپٹ انجیکشن استعمال ہوا۔

> **کیا آپ جانتے ہیں؟** Claude ہیلپ سینٹر کے مطابق Enterprise ادارے اپ لوڈ کی گئی skills اور پلگ انز کو بدنیتی کے مواد کے لیے جانچنے والی skill اسکیننگ کھول سکتے ہیں۔ لیکن یہ حفاظتی جال ہے، پڑھنے کا متبادل نہیں۔ کوئی skill کیا کرتی ہے، اسے سب سے بہتر آپ انسٹال سے پہلے خود اس کا SKILL.md اور اسکرپٹس کھول کر پڑھ کر سمجھتے ہیں۔

## انسٹال سے پہلے چیک لسٹ

دستاویزات کی سفارشات اور میدان کی نشاندہیوں سے نکالی گئی ایک عملی فہرست:

1. **ماخذ کی تصدیق کریں۔** ریپوزٹری کس کی ہے؟ کوئی سرکاری کمپنی یا معروف ڈویلپر، یا جانے پہچانے پیکیج سے بہت ملتی جلتی نقل (typosquatting)؟
2. **SKILL.md شروع سے آخر تک پڑھیں۔** "پہلے یہ ڈاؤن لوڈ کر کے چلاؤ"، "سکیورٹی سیٹنگ بند کرو"، "یہ پتے پر بھیج دو" جیسے جملے خطرے کی گھنٹی ہیں۔
3. **scripts/ فولڈر کا جائزہ لیں۔** اگر ایسی سطریں ہوں جو آپ پڑھ نہ سکیں، چھپائی گئی ہوں یا Base64 میں کوڈ ہوں تو انسٹال نہ کریں۔
4. **بیرونی لنکس چیک کریں۔** اگر skill کسی ویب پتے سے ہدایات یا ڈیٹا کھینچتی ہے تو یاد رکھیں کہ وہ مواد کسی بھی وقت بدل سکتا ہے۔
5. **جو ضرورت ہو وہی انسٹال کریں۔** "سب انسٹال کرو" کے بجائے ایک ایک skill چننا سیاق اور حملے کی سطح دونوں چھوٹی کرتا ہے۔

## کم از کم اختیارات اور خفیہ کلیدیں

Skill کہاں چلتی ہے، یہ بھی اہم ہے۔ Claude دستاویزات کے مطابق Claude API ماحول میں skills کو نیٹ ورک تک رسائی نہیں ہوتی اور وہ چلتے وقت پیکیج انسٹال نہیں کر سکتیں۔ claude.ai میں نیٹ ورک رسائی صارف اور منتظم کی سیٹنگز کے مطابق مکمل، جزوی یا بند ہو سکتی ہے۔ Claude Code میں skills کو اتنی ہی نیٹ ورک رسائی ہوتی ہے جتنی آپ کے کمپیوٹر کے کسی بھی پروگرام کو۔ یعنی مقامی ایجنٹ میں آپ کی انسٹال کی گئی skill آپ کے اختیارات کے ساتھ چلتی ہے۔

اسی لیے کم از کم اختیار کا اصول نازک ہے۔ Claude Code میں skill کے frontmatter کا allowed-tools فیلڈ اس skill کے بلائے جانے پر مخصوص ٹولز کو اجازت مانگے بغیر استعمال کرنے دیتا ہے۔ دستاویزات کے مطابق یہ اجازت آپ کے اگلے پیغام میں ری سیٹ ہو جاتی ہے۔ پھر بھی اگر کسی اور کی لکھی skill میں وسیع اختیارات نظر آئیں تو انہیں دانستہ منظور کیے بغیر انسٹال نہ کرنا اچھی عادت ہے۔

خفیہ کلیدوں کا اصول سادہ ہے: API کلیدیں، پاس ورڈ اور رسائی ٹوکن کبھی SKILL.md یا skill کے فولڈر میں نہ لکھیں۔ جب آپ skill شیئر کریں یا ریپوزٹری میں بھیجیں تو اس فولڈر کی ہر چیز بھی چلی جاتی ہے۔ کلیدیں ماحولیاتی متغیرات میں یا اپنے استعمال کردہ ٹول کے محفوظ شناختی ذخیرے میں رکھیں اور skill کو صرف یہ بتائیں کہ ان تک کیسے پہنچنا ہے۔

اکتوبر 2026 تک skill ایکوسسٹم بہت تیزی سے بڑھ رہا ہے اور یہ بڑھوتری ایپ اسٹورز کے ابتدائی برسوں کے سکیورٹی مسائل کی یاد دلاتی ہے۔ اچھی خبر یہ ہے: skill پڑھنا کسی ایپ کا سورس کوڈ پڑھنے سے کہیں آسان ہے، کیونکہ اس کا بڑا حصہ سادہ متن ہے۔

کیا آپ skill انسٹال کرنے سے پہلے اس کے اندر کھول کر پڑھتے ہیں، یا ستاروں کی تعداد اور ڈاؤن لوڈ کے اعداد پر بھروسا کرتے ہیں؟
