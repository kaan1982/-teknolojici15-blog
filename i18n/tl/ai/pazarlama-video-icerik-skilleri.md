Araw-araw ding gumagawa ng maiikling video, cover at teksto sa likod ng blog na ito. Kaya medyo personal sa amin ang kategoryang ito: mga skill na gumagawa ng marketing, content at video. Ito rin ang larangan kung saan pinakamabilis dumami ang mga skill ng komunidad. Inilista lang namin ang mga halimbawang binuksan namin ang repository at sinuri ang laman. Lahat ng bilang ay hanggang katapusan ng Oktubre 2026.

## marketingskills: library ng marketing na may 52 skill

Ang MIT-licensed na repository na coreyhaines31/marketingskills ni Corey Haines, ang pangalan sa likod ng conversion optimization agency na Conversion Factory, ay isa sa pinakakumpletong koleksyon ng komunidad sa larangang ito. Ayon sa README, inihanda ito para sa mga technical marketer at founder, at nakatuon ito sa conversion optimization, copywriting, SEO, analytics at growth engineering. Sinasabi nitong gumagana ito sa Claude Code, OpenAI Codex, Cursor at iba pang agent na sumusuporta sa Agent Skills standard.

May 52 skill sa skills folder ng repository. Ilang halimbawa:

- **copywriting:** Para magsulat o magpahusay ng teksto ng anumang marketing page, gaya ng home page, landing page at pricing page.
- **seo-audit:** Para suriin at i-diagnose ang mga problema sa SEO ng isang site.
- **ai-seo:** Para i-optimize ang content para sa mga AI search engine, ibig sabihin, para mabanggit bilang source sa mga sagot ng malalaking language model.
- **emails at cold-email:** Para sa mga email sequence, automated flow at B2B cold email campaign.
- **social:** Para gumawa at magplano ng content para sa LinkedIn, X, Instagram, TikTok at Facebook.

Para sa pag-install, inirerekomenda ng README ang command na npx skills add coreyhaines31/marketingskills. Puwede ring pumili ng isa-isang skill.

## Ang marketing plugin ng Anthropic

Ang repository ng Anthropic na anthropics/knowledge-work-plugins ay nagtitipon ng mga plugin na inihanda ayon sa propesyon. Ginawa ang mga ito para sa Claude Cowork at compatible din sa Claude Code. Pinagsasama ng bawat plugin ang mga skill, connector, slash command at sub-agent para sa partikular na trabaho.

Ito ang mga skill sa loob ng marketing plugin: brand-review (sinusuri ang draft ayon sa boses ng brand at style guide at nagmumungkahi ng mga pagwawasto na may before/after), campaign-plan (gumagawa ng campaign brief na may layunin, audience, mensahe, estratehiya sa channel at content calendar), content-creation, draft-content, email-sequence, competitive-brief, performance-report at seo-audit. Inililista ng README na maaaring kumonekta ang plugin na ito sa mga tool gaya ng Slack, Canva, Figma, HubSpot at Ahrefs. Ibig sabihin, ang skill ang nagbibigay ng "paraan" at ang connector ang nagbibigay ng "access".

> **Alam mo ba?** Hindi na lang sa drag and drop sa timeline ginagawa ang mga video; puwede na ring gawin gamit ang code, at dito pumapasok ang mga skill. Naglalathala ang team ng Remotion ng sarili nilang opisyal na set ng skill para sa React-based nilang video framework. Ang HeyGen naman ay nag-aalok ng HyperFrames, na nakabatay sa ideyang "magsulat ng HTML, mag-render ng video," kasama ang mga skill para sa mga agent.

## Para sa video: Remotion at HyperFrames

| Package | Pinagmulan | Ano ang inaalok? |
|---|---|---|
| remotion-dev/skills | Team ng Remotion (opisyal) | 12 skill: paggawa ng video, mga tuntunin sa animation, caption, render, preview |
| heygen-com/hyperframes | HeyGen (Apache 2.0) | Mga skill at handang block para sa framework na ginagawang video ang HTML |

**Remotion:** Ayon sa README, may listahan ang Remotion ng Agent Skills na naglalarawan ng best practices sa pagtatrabaho sa mga proyekto ng Remotion. Kasama sa set ang remotion-create na gumagawa ng bagong video, remotion-markup na may kaalaman sa animation at layout, remotion-captions para sa transcription at animation ng caption, remotion-render para sa export, at remotion-best-practices na nagtuturo sa lahat ng iba. Ginagawa ang pag-install gamit ang npx skills add remotion-dev/skills.

**HyperFrames:** Ipinakikilala ng repository ng HeyGen ang sarili bilang "magsulat ng HTML, mag-render ng video, ginawa para sa mga agent." Ayon sa README, binubuo ang batayang set ng mga skill na hyperframes (paggawa at pag-edit ng video), hyperframes-cli (project scaffold, preview, render), hyperframes-registry (humigit-kumulang 450 handang block ng transition, pamagat, caption at graphic) at media-use (mga gawaing media gaya ng musika, sound effect, larawan at voiceover). May 7 nailathalang skill sa kabuuan.

May kawili-wiling detalye: ang paglalarawan ng video skill sa repository ni Corey Haines ay naglilista rin ng mga pangalang gaya ng Remotion, HyperFrames at HeyGen bilang trigger word. Ibig sabihin, isinulat ang marketing skill para gumana na parang tulay papunta sa mga video skill.

## Ano ang dapat tingnan sa pagpili?

Karamihan sa mga skill sa larangang ito ay galing sa komunidad o kumpanya at napakabilis ma-update. Bago mag-install ng package, makakatulong ang tatlong tanong na ito: Kanino ang repository, at aktibo ba itong ina-update? May tagubilin ba sa SKILL.md na kumokonekta sa mga panlabas na address o humihingi ng credential? Nakakapili at nakakapag-install ka ba ng ilang skill na talagang kailangan mo? Karamihan sa mga install tool ay nagpapahintulot ng pagpili ng isang skill sa halip na "i-install lahat," at pinaliliit nito ang context at ang panganib.

Alin ang pinakamalaking nagnanakaw ng oras mo sa paggawa ng content: pagsusulat ng teksto, paghahanda ng visual, o pag-eedit ng video?
