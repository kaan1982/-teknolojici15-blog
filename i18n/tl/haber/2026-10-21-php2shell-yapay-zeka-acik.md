Noong Oktubre 21, naglabas ang mga developer ng PHP ng agarang patch para sa dalawang kritikal na butas sa seguridad sa core engine ng wika. Ang mga butas na tinawag na "PHP2Shell" at nabigyan ng numerong CVE-2026-109618 at CVE-2026-109619 ay natagpuan sa tulong ng mga AI tool.

## Ano ang nangyari?

Ayon sa Fortune, natagpuan ng AI security testing firm na Calif ang unang bahagi ng kadena noong Agosto 1 gamit ang GPT-5.6 Sol; nakilala naman ng Wiz nang hiwalay ang unang butas noong Agosto 19 at iniulat sa security team ng PHP noong Agosto 24. Sa pagtuklas, ginamit ang sariling tool ng Wiz na Wiz Atlas at ang mga model na GPT-5.6 Sol ng OpenAI at Gemini 4 Argon ng Google.

Pinapahintulutan ng mga butas ang umaatake na magpatakbo ng code nang malayuan sa server nang hindi nagla-log in, at magnakaw ng data sa memory. Ayon sa Wiz, halos lahat ng bersyon ng PHP na inilabas sa nakaraang sampung taon, pabalik hanggang 5.4, ay apektado. Ang pinakamataas na marka ng kalubhaan ay 9.2 sa CVSS scale. Tumatakbo ang PHP sa likod ng humigit-kumulang 70 porsiyento ng mga website sa mundo; ang WordPress lang ay namamahala na ng halos 40 porsiyento ng mga site. Ayon sa na-update na ulat ng Fortune, nagsimulang malawakang abusuhin ang mga butas matapos ang patch.

## Bakit mahalaga ito?

Isa ito sa pinakakonkretong halimbawa na hindi na lang katulong ang AI sa pananaliksik sa seguridad, kundi maaari na ring ito mismo ang tumutuklas. Pero nasa kamay rin ng mga umaatake ang parehong tool, at lumiliit ang pagitan ng paglabas ng patch at pagsisimula ng pang-aabuso. Kailangang i-update agad ng bawat may-ari ng site na gumagamit ng PHP ang kanyang server. Sa mas malawak na larawan, mas mabilis nang lalabas ang mga nakatagong bug sa lumang code ng internet na ilang dekada nang tumatakbo. Ikinuwento namin ang kuwento ng unang programang gumala nang mag-isa sa network sa [artikulo namin tungkol sa Creeper](/yazi/creeper-ilk-virus-zararsizdi/).
