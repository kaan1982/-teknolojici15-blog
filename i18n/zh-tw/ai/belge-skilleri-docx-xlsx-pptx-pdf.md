對人工智慧說「幫我準備一份報告」很容易。困難的是，報告要以真正能開啟、格式不跑掉、公式能運作的 Word 或 Excel 檔案交付。技能的第一個、也許也是最常用的類別，正是這個：辦公室文件。在這篇文章裡，我們只討論已確認存在的技能。

## 四塊基石：docx、xlsx、pptx、pdf

根據 Claude 的文件，Anthropic 提供了四個預先建置（pre-built）的文件技能。它們在 Claude 檔案建立功能的背後運作，Anthropic 在 anthropics/skills GitHub 儲存庫中公開了原始碼。

| 技能 | 做什麼？（出自官方說明） |
|---|---|
| docx | 建立、讀取、編輯 Word 文件。包括格式設定與範本 |
| xlsx | 開啟、編輯試算表，加入公式與圖表，整理雜亂的資料 |
| pptx | 建立簡報、編輯投影片，讀取並解析 .pptx 內容 |
| pdf | 擷取文字與表格，合併、分割 PDF，填寫表單，加入浮水印 |

儲存庫中的說明寫得相當「堅持」。例如 pptx 技能的說明要求，只要 .pptx 檔案以「任何形式」作為輸入或輸出，就要使用它。這是我們在上一篇文章說明的「說明決定觸發」規則的一個官方範例。

## 你可以在哪裡使用？

截至 2026 年 10 月，根據 Claude 的文件，這四個技能在 claude.ai 建立文件時會自動啟用，在 Claude API 中也可以作為預建技能呼叫。在 Claude Code 中，內建並不包含預建的文件技能。但 anthropics/skills 儲存庫可以作為 Claude Code 的外掛市集加入，並安裝 document-skills 套件。依儲存庫中的指示，先以 /plugin marketplace add anthropics/skills 指令加入市集，再安裝 document-skills@anthropic-agent-skills。

授權方面有個區別。儲存庫中的許多技能是 Apache 2.0 授權的開放原始碼。但四個文件技能是以「非開放原始碼，但原始碼可取得」（source-available）的方式提供。也就是說，你可以檢視程式碼來學習，但在自己的產品中自由再散布之前，需要閱讀授權檔案。

> **你知道嗎？** pdf 技能是漸進式載入的教科書範例。根據 Anthropic 的工程文章，填寫表單的指示已從主要的 SKILL.md 中抽出，移到獨立的 forms.md 檔案。Claude 只有在真正要填表單時才會讀取這個檔案。目前儲存庫的 pdf 資料夾中，同時有 forms.md、reference.md 和一個 scripts 資料夾。

## 文件旁的輔助技能

文件製作不只是檔案格式而已。anthropics/skills 儲存庫中，還有其他專注於內容面向的官方範例：

- **doc-coauthoring：** 為共同撰寫技術規格、提案、決策文件等結構化文字，提供逐步的工作流程。它會經過傳遞脈絡、反覆修正和驗證的階段。
- **internal-comms：** 彙整協助以公司偏好的格式撰寫狀態報告、管理層更新、公司電子報、常見問題等內部溝通文字的資源。資料夾中也有範例文字。
- **brand-guidelines：** 把 Anthropic 官方的品牌色彩與字體套用到輸出內容上。它真正的價值，在於示範如何為自己的品牌建立類似的東西。
- **theme-factory：** 內含 10 組可套用於簡報、文件、報告或 HTML 頁面的現成色彩與字型主題，需要的話還能即時生成新主題。

說明中心還提到，Notion、Figma 和 Atlassian 等合作夥伴，已準備好可搭配其自家 MCP 連接器運作的技能。這些在使用產生文件的工具（例如 Notion 頁面）時很有用。

## 在現實中怎麼用？

最有效率的用法，是把現成的文件技能和你自己的小技能結合。例如 xlsx 技能知道怎麼正確產生 Excel，但不知道你們公司的每月銷售表應該有哪些欄位。如果你寫一個說明這件事的簡短技能，兩個技能一起運作，就能產出格式正確、又符合你標準的檔案。

有兩點要記住。第一，anthropics/skills 儲存庫明確寫道，這些技能是「供示範與教學之用」，Claude 自己的行為可能與這裡的實作不同。第二，文件技能需要程式碼執行環境。根據說明中心，要讓技能運作，必須開啟程式碼執行功能。
