پشت همین وبلاگ هم هر روز ویدیوهای کوتاه، کاورها و متن‌ها تولید می‌شود. برای همین این دسته برای ما کمی شخصی است: اسکیل‌هایی که بازاریابی، محتوا و ویدیو تولید می‌کنند. اینجا ضمناً حوزه‌ای است که اسکیل‌های جامعه سریع‌تر از هر جای دیگری تکثیر می‌شوند. ما هم فقط نمونه‌هایی را فهرست کرده‌ایم که مخزنشان را باز کرده و درونشان را بررسی کرده‌ایم. همه اعداد مربوط به پایان اکتبر 2026 است.

## marketingskills: کتابخانه بازاریابی 52 اسکیلی

مخزن coreyhaines31/marketingskills از Corey Haines با مجوز MIT، که پشت آژانس بهینه‌سازی تبدیل Conversion Factory است، یکی از جامع‌ترین مجموعه‌های جامعه در این حوزه است. طبق README برای بازاریابان فنی و بنیان‌گذاران آماده شده و بر کارهایی مثل بهینه‌سازی تبدیل، کپی‌رایتینگ، سئو، تحلیل و مهندسی رشد تمرکز دارد. می‌گوید با Claude Code، OpenAI Codex، Cursor و عامل‌های دیگری که استاندارد Agent Skills را پشتیبانی می‌کنند کار می‌کند.

در پوشه skills مخزن 52 اسکیل هست. چند نمونه:

- **copywriting:** برای نوشتن یا بهبود متن هر نوع صفحه بازاریابی مانند صفحه اصلی، صفحه فرود، صفحه قیمت‌گذاری.
- **seo-audit:** برای ممیزی و تشخیص مشکلات سئوی یک سایت.
- **ai-seo:** برای بهینه‌سازی محتوا برای موتورهای جستجوی هوش مصنوعی، یعنی منبع قرار گرفتن در پاسخ‌های مدل‌های زبانی بزرگ.
- **emails و cold-email:** برای توالی‌های ایمیل، جریان‌های خودکار و کارزارهای ایمیل سرد B2B.
- **social:** برای ساخت و برنامه‌ریزی محتوا برای LinkedIn، X، Instagram، TikTok و Facebook.

README برای نصب فرمان npx skills add coreyhaines31/marketingskills را پیشنهاد می‌کند. می‌توان اسکیل‌ها را تکی هم انتخاب کرد.

## افزونه بازاریابی Anthropic

مخزن anthropics/knowledge-work-plugins از Anthropic افزونه‌هایی را گرد آورده که بر اساس گروه‌های شغلی آماده شده‌اند. این‌ها برای Claude Cowork ساخته شده و با Claude Code هم سازگارند. هر افزونه اسکیل‌ها، رابط‌ها، فرمان‌های اسلش و زیرعامل‌های آن کار را در یک بسته گرد می‌آورد.

اسکیل‌های درون افزونه marketing این‌هاست: brand-review (پیش‌نویس را بر اساس صدای برند و راهنمای سبک بررسی می‌کند و اصلاحات قبل/بعد پیشنهاد می‌دهد)، campaign-plan (با هدف، مخاطب، پیام، راهبرد کانال و تقویم محتوا خلاصه کارزار می‌سازد)، content-creation، draft-content، email-sequence، competitive-brief، performance-report و seo-audit. README فهرست می‌کند که این افزونه می‌تواند به ابزارهایی مثل Slack، Canva، Figma، HubSpot و Ahrefs وصل شود. یعنی اینجا اسکیل «روش» را فراهم می‌کند و رابط «دسترسی» را.

> **می‌دانستی؟** ویدیوها دیگر فقط با کشیدن و رها کردن روی یک خط زمان ساخته نمی‌شوند، با کد هم تولید می‌شوند و اسکیل‌ها درست همین‌جا وارد می‌شوند. تیم Remotion برای چارچوب ویدیویی مبتنی بر React مجموعه اسکیل رسمی خودش را منتشر می‌کند. HeyGen نیز HyperFrames را که بر ایده «HTML بنویس، ویدیو رندر کن» استوار است، با اسکیل‌هایی برای عامل‌ها عرضه می‌کند.

## برای ویدیو: Remotion و HyperFrames

| بسته | منبع | چه عرضه می‌کند؟ |
|---|---|---|
| remotion-dev/skills | تیم Remotion (رسمی) | 12 اسکیل: ساخت ویدیو، قواعد انیمیشن، زیرنویس، رندر، پیش‌نمایش |
| heygen-com/hyperframes | HeyGen (Apache 2.0) | اسکیل‌ها و بلوک‌های آماده برای چارچوبی که HTML را به ویدیو تبدیل می‌کند |

**Remotion:** طبق README، Remotion فهرستی از Agent Skills نگه می‌دارد که بهترین روش‌های کار در پروژه‌های Remotion را تعریف می‌کند. در مجموعه اسکیل‌هایی مثل remotion-create برای ساخت ویدیوی تازه، remotion-markup برای دانش انیمیشن و چیدمان، remotion-captions برای تبدیل گفتار به نوشته و انیمیشن زیرنویس، remotion-render برای خروجی گرفتن و remotion-best-practices که به همه هدایت می‌کند هست. نصب با npx skills add remotion-dev/skills انجام می‌شود.

**HyperFrames:** مخزن HeyGen خودش را «HTML بنویس، ویدیو رندر کن، ساخته‌شده برای عامل‌ها» معرفی می‌کند. طبق README مجموعه پایه از اسکیل‌های hyperframes (ساخت و ویرایش ویدیو)، hyperframes-cli (اسکلت پروژه، پیش‌نمایش، رندر)، hyperframes-registry (حدود 450 بلوک آماده گذار، عنوان، زیرنویس و نمودار) و media-use (کارهای رسانه‌ای مثل موسیقی، جلوه صوتی، تصویر، صداگذاری) تشکیل می‌شود. روی هم 7 اسکیل منتشرشده هست.

جزئیات جالب: توضیح اسکیل ویدیو در مخزن Corey Haines هم نام‌هایی مثل Remotion، HyperFrames و HeyGen را به‌عنوان واژه‌های فعال‌کننده فهرست می‌کند. یعنی اسکیل بازاریابی طوری نوشته شده که مثل پلی به اسکیل‌های ویدیو کار کند.

## هنگام انتخاب به چه چیزهایی نگاه کنیم؟

بیشتر اسکیل‌های این حوزه از جامعه یا شرکت‌ها می‌آیند و خیلی سریع به‌روز می‌شوند. پرسیدن این سه پرسش پیش از نصب بسته کارت را آسان می‌کند: مخزن مال کیست و فعالانه به‌روز می‌شود؟ آیا در SKILL.md دستورالعملی هست که به نشانی‌های بیرونی وصل شود یا اطلاعات احراز هویت بخواهد؟ آیا می‌توانی فقط چند اسکیلی را که واقعاً لازم داری انتخاب و نصب کنی؟ بیشتر ابزارهای نصب به‌جای «همه را نصب کن» اجازه انتخاب تک‌به‌تک می‌دهند و این هم زمینه را کوچک می‌کند و هم ریسک را.

در تولید محتوا بزرگ‌ترین دزد زمان تو کدام است: نوشتن متن، آماده کردن تصویر، یا تدوین ویدیو؟
